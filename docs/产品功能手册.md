# AI 时尚设计平台

### 看趋势 · 做设计 · 看成片 · 管衣橱

> 一条创作链，四个专业舞台。  
> 灵感不再散落，资产不再丢失，成片不再反复导出粘贴。

---

## 这是什么

**AI 时尚设计平台** 是面向设计师、品牌团队、买手与时尚爱好者的 **一体化 AI 工作台**。

过去，你要在趋势网站找灵感、在生图工具里试 prompt、在修图软件里排版、在文件夹里翻 SKU、在 PPT 里拼 Lookbook——**五套工具，五遍导出**。

现在，从「这季流行什么」到「这套 Look 长什么样」，**在同一个界面里完成**。趋势可以一键变成设计起点，设计可以一键试穿、入库，衣橱里的单品可以立刻回到试衣台继续组合。

## 01 · 画布工作台 · L'Atelier

**你的 AI 设计室。说出来的想法，变成看得见的款式。**

### 对话即创作

用日常语言描述想要的廓形、面料、氛围、场景——AI 听懂并出图。  
支持 **多轮打磨**：改颜色、换风格、加细节，都在同一对话里延续，不用从头再来。

**AI 能为你完成：**

| 能力 | 适合什么时候用 |
|------|----------------|
| **文字生款** | 从 0 到 1，快速验证一个 idea |
| **绘制草图** | 创意会，先出结构线稿再深化 |
| **智能改图** | 已有款式，微调颜色/细节/气质 |
| **图案迁移** | 把印花、纹样「贴」到目标服装上 |
| **生成模特** | 为款式准备展示用人体形象 |
| **虚拟试穿** | 在对话里先看「穿上身」的效果 |

### 画布，让灵感可编排

生成图 **一键置入画布**——拖拽、缩放、叠层，像做 Mood Board 一样排布系列感：

- 本地图片拖入即可  
- 选中任意图层，继续发给 AI 修改  
- 预览、下载，提案即用  

### 局部精修

领口、袖口、Logo、腰线——**涂抹要改的区域**，告诉 AI 怎么改，其余部分保持不动。

### 懂你的两种模式

**个人穿搭**  
记录体型、风格偏好、常用场合，AI 越用越贴近你的审美。

**设计师项目**  
按客户/系列独立管理 brief，绑定当季趋势，每个项目都有自己的设计语言。

### 和全平台联通

- 趋势页 → **「用这个趋势开始设计」** → 对话自动带入该季语境  
- 任意满意成图 → **「收入衣橱」** → 变成可复用数字单品

## 02 · 试衣台 · La Pose

**不是滤镜，是 Lookbook 级的上身呈现。**

把「穿什么、谁来穿、在哪拍、什么姿势、什么造型」拼在一起，**一键合成 3:4 时尚成片**——适合电商主图、社媒内容、内部选款会、客户提案。

### 五个维度 · 自由组合

| 维度 | 你可以 |
|------|--------|
| **穿搭** | 从衣橱或预设里选一件或多件，自由叠搭 |
| **模特** | 切换男女、不同气质的展示形象 |
| **背景** | 棚拍、街拍、自然光……切换场景氛围 |
| **动作** | 站立、行走等，让画面「活」起来 |
| **美颜** | 发型 + 发色，完善整体造型 |

### 你说了算

- **多件同搭** — 上下装、配饰一起参与  
- **追加描述** — 「腰间束带」「偏冷调」等细节要求  
- **生成前预览** — 确认描述再出图，不盲抽  
- **历史对比** — 最近几次结果快速切换  
- **不满意就重来** — 同一套选择，换一张新成片  

### 成片之后

| 动作 | 得到什么 |
|------|----------|
| **保存穿搭** | 命名入库，关联全部参与单品，封面即本次成片 |
| **收入衣橱** | 单独收藏这张成图 |
| **下载** | 本地保存，直接用于物料 |

## 03 · 我的衣橱 · La Garde-Robe

**你的数字衣帽间——所有东西，终于有地方放。**

### 四条入口 · 一个仓库

| 来源 | 怎么进来 |
|------|----------|
| **时尚趋势** | 趋势页心动的一图，一键收入 |
| **我的设计** | 画布或试衣台的成图，随时归档 |
| **我的上传** | 手机实拍、平铺图，本地上传 |
| **系统搭配** | 试衣台保存穿搭时，参与单品自动入库 |

每件单品带 **来源标签**，清晰可追溯。

### 自动整理 · 随手好找

入库后 AI **自动识别** 品类、颜色、风格、季节感——  
**上装 · 下装 · 套装 · 鞋子 · 包包 · 首饰 · 配饰 · 未分类**，九大类一目了然。

支持按来源、季节筛选，关键词搜索；也可手动改名、加备注、重新识别。

### 不只存衣服 · 还存 Look

**多选单品 → 保存为穿搭方案**——  
试衣台保存的 Look 会自动关联所有参与衣物，封面就是那张上身成片。

两个视图：**单品** 管每一件，**穿搭方案** 管成套造型。

## 04 · 时尚趋势 · L'Air du Temps

**灵感从哪来？这里开始，也在这里落地。**

### 趋势探索 · 像翻当季 Lookbook

- **为你推荐** — 结合你的风格，优先展示更相关的方向  
- **全部 / 按季 / 搜索 / 收藏** — 快速浏览或精准查找  

点开任意趋势，可见：**名称与故事 · 代表色盘 · 设计语言 · 图库与标签**

**三个动作，把趋势变成行动：**

| | 动作 |
|---|------|
| → | **用这个趋势开始设计** — 打开画布，AI 已站在该季语境里 |
| → | **收入衣橱** — 代表视觉进入你的资产库 |
| → | **加入设计项目** — 锚定到当前系列，团队对齐有据可依 |

### 趋势分析 · 专业情报台

面向需要 **追源头、读报告、看数据** 的深度用户：

| 能力 | 价值 |
|------|------|
| **仪表盘** | 一屏掌握全局与最新结论 |
| **趋势报告** | 完整分析，可对比、可导出 |
| **季节趋势** | 按年/季看演变脉络 |
| **文章库** | 行业内容聚合，全文可搜 |
| **热词追踪** | 关键词热度与时间线 |
| **智能分析** | 一键采集与分析，进度实时可见 |

分析结论 **自动同步到趋势探索**，设计侧直接可用——情报与创作不再断层。

## 一条链 · 四种人生

### 独立设计师 · 一季系列，从灵感到归档

> 读报告 → 收藏方向 → 一键开设计 → AI 多轮出款 → 画布排系列 → 试衣台看成片 → 保存穿搭入库  
> **Season 01，完整闭环。**

### 品牌 / 电商 · Lookbook 不用等摄影棚

> 衣橱里备好 SKU → 试衣台统一模特与场景 → 批量上身成片 → 下载或保存方案  
> **上新节奏，不再被档期卡住。**

### 买手 / 研究员 · 情报独立，也能喂给设计

> 趋势分析跑报告 → 导出结论 → 关键视觉入库或挂到设计项目  
> **研究归研究，落地有通道。**

### 时尚爱好者 · 衣柜数字化，搭配玩起来

> 上传常穿单品 → 完善个人档案 → 试衣台试 Look → 保存心动方案  
> **自己的风格，自己说了算。**

## 团队与品牌 · 可定制呈现

统一模特脸、统一场景、统一 SKU 图，对外输出 **一致的品牌视觉**，无需改产品界面。
