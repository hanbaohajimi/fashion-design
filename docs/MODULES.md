## 模块详情

### 1. AI 设计工作台 (Design Studio)

**技术架构**: React 组件 + FastAPI 后端

**核心组件**:
- `DesignStudioWorkspace.tsx` — 工作区容器
- `ChatPanel.tsx` — AI 对话面板（支持多轮、多图、工具调用）
- `DesignCanvas.tsx` — Fabric.js 画布（图层、缩放、拖放）
- `FabricEditor.tsx` — 像素编辑器（画笔涂抹 + AI 局部修改）

**AI 能力**（通过 DashScope API）:
- 文生图 (wan2.6-t2i)
- 图像编辑 (qwen-image-edit-max)
- 对话理解 (qwen-plus)
- 视觉分析 (qwen-vl-max)

**API 前缀**: `/api/design/`

### 2. 趋势分析中心 (Trend Analysis)

**技术架构**: Vanilla HTML/CSS/JS + FastAPI 后端

**核心页面**:
- 仪表盘 — 统计概览 + 最新报告
- 趋势报告 — 双栏布局（列表 + 详情）
- 季节趋势 — 按年/季节分类的趋势视图
- 文章库 — 爬取文章管理与全文搜索
- 热词 — 维度词云 + 时间线追踪

**核心能力**:
- 多站点爬取（Playwright）
- LLM 趋势分析（LiteLLM）
- 季节分桶与标签
- WebSocket 实时进度推送

**API 前缀**: `/api/trend/`
