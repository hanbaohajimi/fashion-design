# 画布视觉重构 · 分阶段任务清单

> 配套文档：[画布视觉重构-Atelier工作台.md](./画布视觉重构-Atelier工作台.md)（设计理由与规格）
> 本文只讲**怎么做、怎么验、怎么提交**。每个阶段 = 一个可独立提交、可独立回滚的提交。

## 执行纪律（先读）

1. **一次只做一个阶段**，阶段结束跑完验收命令再提交。视觉基线必须逐阶段归因，否则出现退化时无法定位。
2. **每个阶段提交后立刻打一次视觉基线**，不要攒到最后。
3. 提交信息用中文主题（`feat(canvas): ...`），遵循 `AGENTS.md`。
4. 视觉基线只允许更新画布相关截图。若 `fabrics-*.png` / `trends-*.png` / `login-*.png` 发生变化 → **说明 token 改错，回退，不要更新基线**。
5. 视觉回归使用统一的 Docker 环境（`pnpm test:e2e:visual`），本地 macOS/Windows 字体不同，直接跑 Playwright 截图会全量 diff。
6. `playwright.visual.config.ts` 设置了 `reducedMotion: "reduce"` 且 `animations: "disabled"`——**入场动画不会被快照捕捉**，动效必须在浏览器里人工确认。
