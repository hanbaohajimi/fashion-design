## 2. 登录页值得延续的部分

登录页有三块略有转角的布样，细密纹路、自然边缘、接触阴影和灰绿、暖褐、灰蓝配色。它让服装设计的材料直接成为视觉主角，文案和表单又保留充足留白。

后续方向是建立一间有纸、有布、有样衣、有资料的工作室。共享暖纸底、墨色文字、有限的染料色和克制阴影；每个空间借用符合其业务的物件，让视觉形式承担操作意义。

纹理只出现在适合表达材料的局部。真实作品图片、面料颜色、尺寸表格和长篇文字保留干净底面。登录页中的灰绿色只代表视觉气质，不能作为真实面料属性。

## 3. 各空间的具体创新

### 项目首页：正在打开的作品封套

将“继续创作”设计成一份半展开的系列封套：真实封面是主体，侧边露出少量真实作品缩略图，封签承载项目名称、最近访问位置和明确的继续动作。翻开的是同一项目的实际内容。

展开与收起仅作用于封面和缩略图层；项目名称、菜单和按钮保持水平稳定。搜索结果与高密度列表继续采用紧凑排版。无封面时用纸张切口与项目字标，避免让示例作品冒充用户内容。

### 面料库：可展开的布样册

真实面料图占据主要面积，边缘用轻微厚度与挂签建立材料感。挂签集中显示已有编号、成分、克重及可用状态，未知属性明确留空或标记未记录。

点击布样进入近观与全图双视图，并固定“加入当前设计”的入口。只有记录了拍摄比例或物理尺寸时才显示实物标尺；无比例数据时说明缩放仅供看纹理。正反面、垂坠等视图仅在有对应图片时出现。

加入成功后，在原布样上留下明确的“已加入”标记和进入当前设计的动作。键盘与触屏同样能够展开信息，不能依赖悬停才能看到规格。

### 色料实验：同一款式的试色台

用真实候选组成规整的试样条，保留一致的图像比例与中性背景。上方固定当前母图和修订，横向是实际实验变量；比较时让同一款式同一区域对齐，减少来回寻找差异。

色片可作为参数入口，但不能靠 CSS 给衣服蒙一层颜色来冒充生成结果。预览、排队、执行中、成功、失败分别有明确标签；模型尚未产出时保留空位及任务状态。

选中试样后，显示来源、参数与“采用为新修订”的动作。必要时采用前后分割查看；涉及面料质感与版型变化时，保持原图可直接查看。

### 趋势研究：有出处的剪贴簿

以研究主题组织主图、真实来源、色彩笔记和用户摘录，形成一页研究展板。图片可以适度错位，文字与操作保持整齐；每条资料都保留来源、时间和原文入口。

将选择资料后“整理为设计简报”作为主要接续动作。系统提取的色彩或推断需要注明来源与不确定性，不把编辑性排版当成已经完成的趋势分析。

### 创作画布：材料、工序、作品各有形态

参考与面料节点采用轻微材料边缘，工序节点采用简洁标签和参数结构，生成作品保留大幅完整图像。连线仍清楚表达真实输入输出；选中关系时局部强调路径，运行时只标记真实执行的分支。

避免为功能节点增加随机角度、装饰针脚或持续摆动。画布首先服务拖拽、选中、连线和精确查看，装饰不能扩大命中范围、遮住端口或降低信息密度。

### 款式与系列：样衣档案与系列陈列

款式详情以当前修订的大图为主，侧边形成可比较的修订样本条，清楚标出采用、候选与来源。只有用户记录过的决策理由才能显示为设计理由。

系列页采用等高的作品陈列，允许在有明确规划时保留待补款位，并显示其真实目标。不同款式共享观察尺度；切换比较维度时保留作品位置。不要凭空生成计划空位或完成百分比。

### 印花、样衣与交付：从铺布到检样资料

印花工作区可用铺布与裁片窗口帮助理解重复方式；重复单位、裁片与缩放必须对应实际参数。未具备真实尺寸数据时，避免显示具有生产精度含义的尺规。

样衣问题像有编号的检样标签，锚定真实照片位置，并关联问题、负责人、修订与处理状态。技术包和展示集借用资料夹的页签与封签，但尺寸表、审批记录、下载状态保持规整、清晰。

## 4. 统一的操作语言

| 物件动作 | 对应产品行为 | 约束 |
| --- | --- | --- |
| 翻开封套 | 打开项目或查看项目摘要 | 不隐藏主要操作；减弱动态时直接切换 |
| 展开布样 | 查看纹理与规格 | 原图与属性真实；触屏、键盘可用 |
| 选取试样 | 选择比较对象或采用候选 | 选中状态持续可辨；采用需要明确动作 |
| 夹入资料 | 引用趋势、素材到当前设计 | 显示加入结果与目标项目；失败可重试 |
| 挂上检样标签 | 标记实际样衣问题 | 编号与照片、修订绑定；不可纯装饰 |

动效承担开合、选择和加入的反馈。沿用现有时长 token、可见焦点与减弱动态规则；没有真实状态变化时保持安静。材料边缘可用 CSS 或自有 SVG 表达，避免为简单纸纹引入大图和额外动画库。

## 5. 建议落地顺序与验收

1. 先做面料库：最贴近登录页的织物语言，验证样本、规格、选取、加入设计的完整闭环。验收时同时检查无图、长规格、未知比例、加载失败和手机操作。
2. 再做色料实验：让材料感进入比较与决策。验收母图修订绑定、不同任务状态、失败重试和采用结果，确认视觉不误导真实质感与颜色判断。
3. 然后做项目封套与趋势剪贴簿：建立进入系统、寻找灵感、继续工作的连续气质。用实际封面和不同纵横比的真实内容检验版式。
4. 最后扩展画布、款式、系列与交付：逐个保留原有业务和高密度工作效率，补齐实际下一步事项与跨模块上下文。需要新增数据的能力单独定义 API 和权限。

每一轮同时验收视觉和业务：用户能否认出当前材料与作品、能否完成当前决策、进入下一步时是否保留正确对象与修订。检查手机、键盘、减弱动态、错误状态和真实内容；新增视觉基线不能代替人工判断。

这份提案与原方案中的未完成能力共同构成后续工作，不能将文档中出现的设计视为已经实现。
