## 🎨 设计系统核心特点

### 色彩系统

```
背景层级：
├─ #0A0A0B (深黑基础背景)
├─ #1A1A1C (卡片/面板)
└─ #2A2A2C (浮层/弹窗)

强调色：
└─ #E9522C (温暖橙红 - CTA/重要状态)

文字颜色：
├─ #FAFAFA (主要文字)
├─ #A8A8A8 (次要文字)
└─ #6B6B6B (辅助文字)
```

### 字体系统

```
衬线字体（标题、品牌）：
└─ Georgia, "Songti SC", serif

无衬线字体（界面、正文）：
└─ "Inter", "PingFang SC", "Microsoft YaHei", sans-serif

层级：
├─ Display: 48px / 36px / 28px
├─ Heading: 24px / 20px / 18px
├─ Body: 16px / 14px / 13px
└─ Label: 14px / 12px / 11px
```

### 间距系统

```
基于 4px 栅格：
└─ 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96px

组件间距：
├─ xs: 8px
├─ sm: 16px
├─ md: 24px
├─ lg: 32px
└─ xl: 48px
```

## 🎯 设计原则总结

1. **留白为王** - 充足的空间让内容呼吸
2. **对比清晰** - 强烈的字号、颜色对比
3. **层级分明** - 通过大小、颜色建立层级
4. **专业克制** - 避免过度装饰
5. **视觉一致** - 相同元素保持一致
6. **响应迅速** - 流畅的动效反馈
7. **时尚感知** - 借鉴时尚行业美学
