# Atelier 全系统界面优化实施

依据：refactoring-ui；方向：保留暖纸、深墨、茜草色，桌面明显重排。

## 实施基线

开始前工作区已有 API、共享类型、创作记忆、画布、项目聚焦和视觉基线改动。本次保留全部已有行为与文件，不更改后端契约。源文件快照保存在 `output/ui-refactor/before-web-src.zip`，规划阶段截图位于 `output/playwright/refactoring-ui-audit/`。

## 规范

- 唯一运行时规范：`apps/web/src/styles/design-system.css`。旧 token 通过别名兼容，不导入旧主题。
- 页面标题 32px、模块标题 24px、章节 20px、正文和文字控件 14px、辅助信息 12px。
- 侧栏 216px、检查器 320px；默认/紧凑/主控件 36/32/40px，触控 44px。
- 画布独立全屏，右侧面板默认 384px、范围 320–480px；可用画布至少 640px，空间不足时收起面板。
- 间距来自既有 token：组内 8–16px，组间 24–32px。正文说明独立限宽，表格保持工作宽度。
- 每个活动工作区至多一个主动作。图片判断使用 contain，展示封面明确选择 cover。
- 普通表单自然滚动，操作条占据正常布局，不覆盖输入；画布保持独立全屏。
- reduced-motion 取消装饰运动，状态文本、焦点、选中和错误恢复保留。

| 语义         | 当前运行时值与用途                                                                       |

| 阴影         | 普通控件 shadow-ui；素材用 material-1/2/3；菜单 popup；弹窗 modal                        |

## 审查与规则

1. 多层导航压低内容 → 分组侧栏与紧凑页头（§2.1、§2.4）。
2. 长表单弱化作品与修订 → 图片前置、紧凑对象选择、章节目录（§2.1、§2.5）。
3. 成员管理抢占评审 → 默认评审、次级成员页签（§2.4）。
4. 首页主动作竞争 → 有项目突出继续，无项目突出新建（§2.8）。
5. 自定义小字号 → 共享控件与统一 token（§1.5、§4.1）。
6. 实验参数与结果分离 → 配置与结果并列（§3.3、§3.6）。
7. 旧规范与活跃 CSS 冲突 → 入口 token 检查与文档澄清（§1.5）。
8. 图片失败状态不一致 → 共享预览与重试（§7.4）。
9. 局部控件与装饰不一致 → 统一上传、表单、间距和浮层（§8.1、§8.5）。

## 验证记录

### 实际入口与呈现约束

运行时页面为 `/login`、`/auth/confirm`、`/`、`/fabrics`、`/trends`、`/[projectId]` 和 `/[projectId]/studio`；另有全局错误边界。`login.module.css`、`design-tokens.css` 等未导入文件不作为运行时规范。`design-contract.spec.ts` 从真实路由递归读取相对 import 和 CSS @import，防止历史文件掩盖 token 缺失。

工作室保留原 tab 值、三组顺序、assetId 优先级和 URL replaceState 策略。侧栏 216px，全组展开；移动端统一选择器覆盖 11 项。桌面模块自己的标题即工作区页头，省去重复的公共标题行。创作进展从侧栏打开原生 Dialog，完整记录仍可跳转。

资料编辑保持自然滚动；保存条处于文档流，不覆盖最后字段。短高度、窄屏及相当于 200% 缩放的 683×384 视口可重排。既有对象默认展示首个真实记录，多个对象才出现可展开切换列表；指定 assetId 仍进入新建。

图片默认 contain，展示封面显式 cover；缩略图内不嵌套重试按钮，主预览保留重试。印花背景有独立加载与失败反馈，不改变平铺尺度和坐标。上传入口只包装原有处理函数，不增加未实现的拖放提示。

SaveBar 的 formId 和 primary 均为可选；未传参的调用保持兼容。ImagePreview 增加 fit/retryable，AssetPicker 增加 compact，不改变选择顺序或数量。请求键、expectedVersion、409 恢复与人工复核语义沿用原实现。

### 设计变量与对比度证据

所有新增公共尺寸位于 `design-system.css`：app-header-height、workspace-nav-width、inspector-width、editor-header-height、text-page-title、text-module-title、text-section-title、page-gutter。页面仍使用原有字号、间距与材料阴影体系。

样衣“待处理”徽标在扩展数据检查中发现原文字/底色组合仅 4.02:1。使用 skill 的 generate_palette.py 从原 warning 色生成色阶，再用 check_contrast.py 验证 #8c5831 / #f4efe9 为 5.17:1；新增 warning-ink 只调整警告文字，保留原状态底色。活跃文字控件统一至少 14px；元数据仍可为 12px。

### 修改范围、保留与限制

本次集中修改 Web 共享控件/设计变量、工作室外壳和 11 模块、项目/登录/素材入口、画布外壳与浮层样式，以及相关浏览器/视觉测试和文档。本次没有修改后端 API、数据库、队列和生成计费协议。

工作区原有的 API/共享类型、创作延续、项目聚焦、任务反馈与画布成果均保留。执行期间还观察到 package.json/锁文件及其他视觉/动效文件的独立变化；这些未被回退或纳入本任务的依赖安装操作。本次没有执行 Git 提交。

截图和浏览器测试使用可重复的 API fixtures 与测试服装图；真实材质质量、真实账号权限、队列、MinIO 和生产计费链路不由 mock E2E 证明。本次未运行数据库集成测试。对比度工具覆盖文字与祖先背景，图片、伪元素和复杂叠层仍依赖人工图像审查。未对全部异常状态的笛卡尔组合建立截图；共享状态、全部模块正常/空数据/只读及主要异常分别覆盖。

开发服务仍有既有 Sentry 导入弃用与 tldraw 部分翻译 key 提示，未为界面调整扩展到依赖升级或翻译重写。

收尾发现并修正两项细节：空项目库顶部和空态原有两个实心新建按钮，现仅空态主动作醒目；触屏工作室复选项标签与滑块扩大为 44px 可操作区域，草图下拉框使用紧凑控件 token，触屏随 token 扩大。对应候选图重新审查后提升，原图备份保留。
