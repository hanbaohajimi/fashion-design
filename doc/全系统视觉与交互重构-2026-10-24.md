## 设计契约

中性浅灰 `#F5F5F5` 页面、白色面板、`#FAFAFA` 次级表面、`#D7D7D7` 图像台；文字三层 `#181818 / #555555 / #6A6A6A`。

主动作 `#314EC4`，悬停 `#253CAE`，按下 `#192B97`；选中浅底 `#EBF1FF` 加标记；错误 `#B92727 / #FFEBED`。茜草仅用于品牌入口。工作区无衬线，正文 400、强调 600。

设计变量唯一运行时入口为 `apps/web/src/styles/design-system.css`。生成参数：neutral `--grey --temperature neutral --lightest 96 --extended`；action `--base hsl(228,60%,48%) --extended --cap 8`；danger `--base hsl(0,65%,44%) --cap 8 --toward cool`；success `--base #4a6b57 --cap 8`；warning `--base #8c5831 --cap 8`。

所有必填内容可见；高级字段可折叠但保留真实摘要与草稿。校验自动展开首个错误所在区域。不得自动保存、发布或生成。

## 当前组件与颜色规范

`design-system.css` 是唯一运行时主题，`design-tokens.css` 与 `design-system-v2.md` 已标记归档。兼容别名仅解析到现有语义变量，不建立第二套主题。

| 语义       | 默认 / 悬停 / 按下                           | 说明                                         |
| ---------- | -------------------------------------------- | -------------------------------------------- |
| 主操作     | `#314EC4 / #253CAE / #192B97`，文字白色      | 保存、提交、生成；完成导出后下载接替主操作   |
| 选择       | `#EBF1FF / #253CAE`，轮廓 `#314EC4`          | 导航、页签、候选与对象；同时保留标记或轮廓   |
| 焦点       | `#314EC4`                                    | 2px 焦点环，保留偏移；表单输入边界 `#808080` |
| 成功       | `#4A6B57 / #EFFBF5`                          | 文字、图标与状态浅底                         |
| 警告       | `#8C5831 / #FFF6EB`                          | 待处理、待确认                               |
| 错误       | `#B92727 / #FFEBED`                          | 字段、错误提示与局部状态；图片本身不染色     |
| 运行、信息 | `#253CAE / #EBF1FF`                          | 图标、文字与状态；没有虚构百分比             |
| 禁用       | 文字 `#6A6A6A`，底 `#F5F5F5`，边界 `#D7D7D7` | 保留作品原色，不降低整个组件透明度           |
| 品牌       | `#B0452A`                                    | 登录与少量品牌标识，不承担常规导航与主操作   |

正文和控件 14px，手机文字输入 16px；元数据 12px；页面、模块与区块标题分别 32/24/20px。工作界面使用已有无衬线字体栈，400/600 字重。间距沿用 4px 基础尺度，字段间 16px，组间 24–32px。控件圆角 6px、容器 8px、弹窗 12px。

共享接口：

- `Button` 保留原 variant / loading API，独立禁用色；加载标记不改变按钮宽度。
- `Badge` / `Notice` 支持 success、error、warning、info、running，状态图标不替代文字。
- `WorkspaceHeader` 组织标题、说明、当前上下文和次级动作。
- `FormSection` 使用原生 details，真实摘要、受控展开与首个 invalid 字段定位；隐藏内容保持挂载。
- `ObjectSwitcher` 将对象列表按需展开，选择继续调用 `beforeChange`。
- `ActionBar` 只提供状态和动作布局，不自动决定业务动作。
- `SaveBar` 兼容 busy、dirty、canEdit、formId、primary，补充 label 和 error。
- `EditorChapters` 只切换编辑视图，章节共享 `useStudioForm` 的同一份草稿。

颜色审阅产物由 `node scripts/export-design-system.mjs` 生成，包含实际解析的 242 个变量、33 个颜色配对、JSON、CSV、CSS 快照及 HTML 预览。普通文字使用 4.5:1 门槛；必要的输入边界、焦点和选择轮廓使用 3:1 门槛。33 个配对均通过，文字配对另由 skill 的 `check_contrast.py` 复核。导出 CSS 只供审阅，不导入应用。
