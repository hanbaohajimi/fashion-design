# 实施与真实素材验收交接

更新：2026-11-04。衣架、素材准备、搭配版本和双模式输入已实现；真实素材矩阵的 29 款正面及侧图均已确认保存。最终代码的自动化检查、完整构建及混排独立视觉复核已完成，在已检查的静态图片和动态抽帧中未发现剩余阻塞问题。该结论限于本矩阵的素材与衣架渲染，不包含尚未真实验收的多件试穿效果。

## 已实现的使用流程

- 商品展示新增 `mode=wardrobe`，保留展示包与原单件实时试穿；工作台图片、款式档案可进入单品准备。
- 当前项目内选择或上传来源，提取／补全后并排核对、校准挂点，再确认单品修订；原图和历史修订不覆盖。
- 衣架支持侧挂、悬停转正、邻近让位、聚焦与前后浏览；肩部衣架、裤夹、挂钩及托架独立绘制，服装等比完整显示。触屏通过点击查看并加入搭配。
- 搭配默认替换同部位单品，明确选择后可叠穿、调整层次、移除与撤销；本机草稿、正式搭配和试穿快照分别保存。
- 模特试穿使用原始模特及完整搭配快照，显式提交；本人模式复用现有摄像头控制器，串行合并完整搭配更新，截图绑定已应用快照。
- 本人参考图按部位分组，内搭与外套独立可见；历史快照参考图不改写。结果来源保留全部单品，而非随意归到某一款式修订。
- 暖白、深绿、字体、共享控件与浮层沿用现行设计系统；未重设计全站。

## 最终视觉证据与范围

最终混排证据位于 `output/wardrobe-provider/inspection/full-groups-20261104-v4/`，其中 `UI-HANDOFF.md` 与 `coverage-summary.json` 记录真实已保存的单品修订、PNG 摘要、挂点及各场景。浏览器使用生产衣架组件和真实服装图片，但项目壳与只读 API 为测试模拟；真实数据库和私有图片一致性由前述终态审计独立验证。

静态观图覆盖 A／B／C 的桌面与窄屏陈列、正面聚焦、关闭返回及挂具接触。A／B 最终 v4 的 200 张图片中，187 张与已检查的 v2 字节一致，13 张差异均重新实际打开检查；C 使用修复后的 v4。早期 v2 虽自动化通过，但实际观图发现鞋托遮标题与窄屏托架被裁，已保留失败记录并修复、重跑。

历史录像的抽样包括快速扫过、反向、聚焦和关闭。A／B 使用 v2 录像，C 使用 v4。2026-11-05 复现用户反馈时查明，测试的页面设置覆盖了浏览器上下文的正常动效设置，因此这些录像可证明状态切换，连续转动效果应使用下方的新录制验证。逐项观察见 [真实素材验收的最终复核记录](PROVIDER-REALISM.md)，精确文件及摘要保存在 `output/wardrobe-provider/reviews/2026-11-04-groups/final-visual-review.json`。

2026-11-05 的悬停修复录制位于 `output/wardrobe-provider/hover-motion/`。其中 `reference-vs-rail-final.mp4` 为原速对照，左侧为第二段参考视频，右侧为修复后的生产构建，两边操作时间独立。`before-normal-trace.json` 和 `rail-final-trace.json` 记录同样 14 次指针进入事件。业务代码在衣架区域主动读取边界／样式的次数分别从 196／392 降为 0／0。最终样本的帧间隔中位数 16ms、最长 21ms，来自本机 Chromium 测量。两张已审核照片绕各自挂点投影转动，挂具和邻件使用同一 420ms 时间曲线。延迟加载浏览器验证确认正面仍在解码时保留侧挂图，解码后正常转动，减少动态效果偏好仍有效。

根据用户反馈，位移另外约束到横杆内侧。1920px 宽屏混排复测覆盖静置、两端悬停、邻件让位和反向切换，共 13 个采样状态，挂点最小端部间距为 7.95px，证据为 `rail-edge.json` 和两端截图。触屏模拟仍见 `output/wardrobe-tryon/touch-20261104-v8/`。

边界修复后的同一份生产构建通过 22 项相关单测与六场正常动效浏览器回归。29 款分别在 1440px 与 390px 检查了静置、快速扫过、反向、聚焦返回与横杆两端约束。A 桌面记录位于 `groups-rail/`，暂停后完成的其余五场位于 `groups-rail-resume/`，各场保存 `coverage.json` 和 `recording.json`。

## 未纳入本轮通过结论

真实多件模特试穿、物理摄像头持续生成、普通背景／人物遮挡／整套拆分等其他来源效果，仍按各自能力独立验收。真实服装 PNG、参考图合成或浏览器测试均不能替代这些供应商效果验证，多件能力不因此自动启用。

升级时先保留原摄像头配置，执行 `pnpm db:generate`、`pnpm db:deploy`，按顺序应用 `20261030010000_wardrobe` 和 `20261030011000_wardrobe_trial_snapshots`；未改写旧迁移。开关与接口见 [实施说明](IMPLEMENTATION.md)。本轮未提交、推送或部署，已有无关改动保留。
