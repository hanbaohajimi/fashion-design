## 第一段：连续试衣

| 时间／状态 | 视频直接可见 | 本系统映射 |
| --- | --- | --- |
| 约 0–6.5 秒 | 侧边试穿区显示等待；人物身上的绿色蓬松外套切换为棕色外套 | 保留旧预览、显示任务反馈，完成后显示对应搭配版本 |
| 同一过程 | 搭配缩略图约五件，最后一件更换；帽、裤、鞋大致延续 | 同一份完整搭配中按明确操作替换单品，不能依赖模型自动记住旧单品 |
| 控件 | 可见移除、重新开始等入口；视频未完整展示其所有后果 | 删除、撤销、失败重试作为本系统明确交互，不声称由视频验证 |
| 其余画面 | 商品卡和其他陈列效果 | 不纳入本次范围 |

画面连续不代表真实模型无等待或能可靠保留每一件服装。供应商效果须另外验收。

## 第二段：衣架

| 视频行为 | 必须复刻的边界 | 验证方法 |
| --- | --- | --- |
| 默认约十件侧挂 | 挂点稳定；不裁切长衣主体 | 桌面截图、长短款并排 |
| 悬停转正与邻近让位 | 当前衣架不被整排滚到中心；近邻位移最大，远邻衰减 | 指针逐件扫过、反向、测位置 |
| 连续悬停与移出 | 上一件收回和下一件展开衔接；移出归位 | 正常动态录屏、稳定命中区检查 |
| 约 8.1–8.6 秒点击聚焦 | 单品居中，陈列淡化，名称序号和关闭入口显现 | 聚焦截图、键盘焦点检查 |
| 约 9.5–12.3 秒前后切换 | 当前详情切换，保持聚焦状态 | 前后按钮及名称／序号断言 |
| 约 13.1–13.6 秒关闭 | 返回原陈列位置和浏览上下文 | 关闭前后比较、搭配不丢失 |
| 尾部手机系统控制中心 | 非产品行为 | 排除 |

## 明确属于本系统扩展

类别筛选、名称搜索、分组导航、裤夹／挂钩／鞋包托架、加入搭配、替换撤销、显式叠穿、层次排序、本人／模特模式、草稿、权限、版本来源和结果保存均为批准计划中的扩展。扩展使用现有森织视觉，不照搬参考视频的品牌皮肤。

衣架技术检查可用明确标注的透明几何测试素材，但这只能验证位置、比例、交互和布局。真实单品提取、遮挡补全、边缘质量和模型试穿效果须用真实样本另行验收；不能把测试素材截图记作这些项目通过。

## 录屏对照

浏览器测试开启录屏，在正常动效下停留关键姿态，并执行连续反向悬停、聚焦、前后切换和返回。`scripts/manual/compare-wardrobe-video.mjs` 可将第二段原视频与浏览器录屏并排输出到 `output/wardrobe-tryon/browser/video-comparison.mp4`。左侧是原视频，右侧是测试环境；两段保留原速、独立操作时间轴，较短片段停留最后一帧，不把操作时间差当成动画速度差。

原视频中的服装细节不是测试 SVG 的质量标准；此对照用于审查交互次序、让位规律和空间过渡。真实单品视觉验证仍单独列在 [ACCEPTANCE.md](ACCEPTANCE.md)。
