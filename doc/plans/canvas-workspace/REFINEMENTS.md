## 复核结论与范围

原方案中的独立白板文档、后台节点与业务命令、Agent 明确指令执行、只读流程、迁移和三阶段分支已在上一轮落地。本次发现并修复的是交互、恢复和视图隔离的遗漏，不能用上一轮 CI 结果替代这些行为的验证。

原有导航、项目顶栏、设计助手、图片及工具详情、任务和其他页面继续复用。修改集中在无限白板及其原有便签、色卡组件；后台业务模型、模型参数和计费策略未变。

## 已补齐的行为

| 场景 | 当前行为 |
| --- | --- |
| 复制与引用 | 同项目复制的图片实例立即解析到真实素材，不需要等待刷新；容器递归展开、引用去重，保留 16 项上限。 |
| 便签和文字 | 空白新便签只保存布局；输入后建立素材。清空已保存文字会提交内容变更，避免 Agent 继续读到旧文字。兼容原生文字和便签。 |
| 画框与分组 | 创建、分组和解除分组引起的自动选择只整理布局，不自动上传框内原始笔画；随后主动选择仍可固化草图并加入助手引用。 |
| 保存失败 | 项目和白板文档两层载入均提供重试；素材或布局保存失败保留草稿，恢复按钮避开底部工具条。 |
| 回执与版本 | 素材命令复用持久化操作编号；刷新恢复和重试不重复创建。旧布局回执恢复后继续保存较新的布局，不倒退已知版本。 |
| 保存期间继续编辑 | 先提交较新的素材内容，再确认对应布局已保存，避免界面显示新文字而后台仍是旧版本。 |
| 视图隔离 | 隐藏白板失去键盘焦点并进入只读状态。流程视图的删除、粘贴等操作不再传入隐藏白板。 |
| 个人视野 | 平移和缩放独立保存在本机，按账户和项目隔离；刷新、助手宽度变化、窄屏切换保持视野中心，不写业务节点或布局版本。 |
| 历史与权限 | 首次恢复旧白板保留素材尺寸和位置；只读项目的便签、色卡及绘制入口遵守只读状态。 |

## 界面与操作

- 根据设计师确认，直接复用原自由白板的 `ToolRail` 及图标样式，移除新增顶部工具栏和节点阶段的底部简化栏。工具栏相对当前白板居中，随助手展开、收起与宽度调整适配。
- 保留选择、抓手、草绘、上传、文字、箭头、便签、色卡、固定素材、面料、系列和趋势入口。草绘、上传、面料、趋势、系列接入当前工作台已有面板及业务服务；不接回旧白板写入链路。
- 同一栏新增“设计工具”入口，继续使用统一工具目录中的需求分析、方案生成、服装评估、局部修改、调整图片尺寸及其原有参数面板。执行仍经过白板业务命令记录后台节点，流程图保持只读。
- 选中对象后提供详情、分组、解除分组和取消选择；更多菜单保留其他素材类型、自由手绘、画框、复制、对齐、等距分布、移除摆放、撤销、重做与缩放。文字和自由手绘保留颜色、粗细或字号设置。
- 增加空白状态和简短操作说明。手机保留原工具栏横向滚动，设计工具和更多操作保持可见；触控按钮至少 44px。隐藏白板时卸载工具控件，避免快捷键和弹出菜单穿透到流程视图。
- 色卡支持直接点击或键盘进入名称编辑；只读状态隐藏新增、移除入口并禁用编辑。
- “查看全图”限制自动放大并为操作区保留留白，缩放不影响设计语义。
