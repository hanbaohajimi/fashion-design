# 桌面工作台重构

## 已确定的设计契约

作品为中心，暖白目录、深绿文字、浅绿选择态，沿用现有设计系统。保留十二项工作室功能、URL、深链、角色权限、显式生成确认与人工复核。保留逐字渐显、绘画等待与弹性反馈，业务状态不等待装饰完成。

桌面目录184px；工作区字号12/14/16/24px；普通边界0.5px。助手默认384px、最小320px、最大480px，作品区最小640px。容器不足时改用抽屉，手机使用作品/流程/助手切换。长表单使用文档流，画布与助手独立滚动。

本机草稿按账号、项目、会话/对象隔离，300ms合并写入，保留服务端基线和冲突副本。不持久化File、Blob URL或签名URL，不自动提交业务修改。
