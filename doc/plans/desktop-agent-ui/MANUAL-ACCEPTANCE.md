# 人工与真实设备验收单

本文件是尚未执行项目的操作步骤，不是通过回执。自动化结果见 IMPLEMENTATION.md；fixture、DPR 与合成 composition 事件不能替代下列验证。

## Windows 中文输入法

1. 使用隔离项目，进入设计工作台助手。打开 Windows 自带微软拼音，输入“保留领口修改袖型”，用 Enter 选择候选。
2. 观察网络：选择候选及紧随的伴生 Enter 均不得发送请求，正文保留。随后单独按 Enter 应只提交一次。
3. Shift+Enter 换行；按住 Enter、双击发送及键盘/鼠标同时提交，最多产生一次受理。
4. 回复期间输入下一条正文，点击“停止回复”。当前正文立即停止等待，已收到部分保留并显示未完成；下一条草稿保持。
5. 切换两会话、两个项目后刷新，分别检查正文和引用。退出账号再登录另一账号，不得恢复前一账号草稿。

记录：Windows/输入法版本、浏览器版本、时间、项目ID、请求数、结果、截图或录屏路径。不要在记录中包含密钥或未脱敏业务正文。

## 滚轮、键盘与焦点

1. 用物理滚轮回看长历史，保持流式回复运行；图片解码、提案展开、输入框增高和分栏拖动均不得把阅读位置拉到底部。
2. 点击“有新消息”返回最新。打开设计要求、素材选择器和助手抽屉，Tab/Shift+Tab 不逃出当前模态层，Escape 返回原触发器。
3. 拖动分栏后依次用 Escape、失焦、取消指针和缩放窗口中止手势；核对宽度、开合、焦点、光标和刷新后的偏好。
4. 进入技术包长表单，确认页面仍为文档流滚动；画布和助手保留各自滚动区。

## 系统缩放与手机

1. Windows 显示缩放分别设置 100%、125%、150%，记录实际屏幕分辨率和浏览器窗口尺寸；检查默认、hover、菜单展开和动效终态。
2. 浏览器实际设置 200% 缩放，检查项目任务、生成确认、停止、保存和发布均可访问；仅长表格允许局部横向滚动。
3. 真机或真实软键盘打开助手输入。测试一行、十行、长粘贴和16项引用；发送/停止保持可达，输入区独立滚动。切换作品、流程、助手不丢草稿。
4. 切换减弱动态和 Windows 高对比度，确认状态文字、选中态、焦点环与主要操作可辨识。

## 真实供应商与发布前链路

本轮已用真实PostgreSQL、Redis、队列、MinIO和受控模型完成隔离集成，真实Next生产代理流式验证也已通过。下面是发布环境与真实供应商的复核步骤，不把受控链路等同于供应商验证。

默认不执行付费调用。供应商验证需使用明确配置的受控额度和隔离项目，单独记录供应商是否实际终止，不能由平台 canceled 推断退款或供应商已停止。

1. 先部署增量迁移和能读取 canceled 的后端/前端，再开启停止入口。
2. 发送助手请求后由另一实例停止，观察数据库终态、部分正文及迟到提案/生成动作是否被隔离。
3. 在终态提交与停止请求之间制造竞争并重复停止，确认返回权威终态。重启处理实例后通过 GET 读取快照/数据库结果，不重新 POST。
4. 分别验证数据库、Redis、队列与 MinIO 的隔离测试项目；图片任务停止与助手停止互不连带，保存、复核、发布、导出仍独立确认。
