# 实时试穿界面重构

2026-10-29。只调整实时试穿页面及素材选择器的可选展示入口，继承 `apps/web/DESIGN.md` 的暖白、深绿与字体尺度。

## 页面行为

- 桌面主画面配 300px 操作栏，服装、费用、授权及操作集中排列。内容宽度不足 880px 时变为单栏。
- 本地画面先占据主区，真实远端首帧到达后显示试穿结果，原始画面进入可收起的小窗；小窗保留独立空间，不覆盖服装主体。两个 video 节点保持挂载。
- 手机主画面约 34dvh，服装使用横向摘要，操作固定在底部并预留安全区与文档尾部空间。
- 保留真实首帧和换衣后新帧的保存门槛、显式授权、幂等重试、隐藏及离页停止。素材选择器默认展示兼容原有页面；仅试穿页使用自定义入口。
