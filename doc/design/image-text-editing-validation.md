# 图片文字编辑、选区与恢复验证

日期：2026-11-09。承接[扩图验证](image-outpaint-validation.md)和[Lovart能力对照](lovart-capability-review.md)。本轮补齐图片内文字的明确识别、原文核对、替换/删除及局部重绘接线。未调用付费模型、启动生产Worker、提交推送或运行全仓检查/CI。

## 实现范围

- 图片工作区增加“修改文字”，打开工具不调用OCR。点击“识别图片文字”才读取当前素材；识别失败、没有文字均允许手动添加区域。
- 最多24个识别区域，每处原文和替换最多300字符，一次提交1至8个实际变化区域。留空替换为删除；大小写、标点和换行保留。用户纠正原文时，仅在替换尚未改动的情况下同步替换，避免制造反向改写。
- 选区按原图归一化坐标保存。当前区域提供实际44px移动/缩放操作点，其他区域保留被动编号，减少密集文字的遮挡。缩放使用实际图片边界校正拖动坐标，方向键移动1px、Shift为10px。
- 一次手势只接受一个指针，Escape、失焦和指针取消撤回本次操作。选区手势通过局部上下文暂停图片平移/缩放；不在图片的渲染回调中修改ref，也不通过临时组件类型引起选区重挂载。
- 草稿沿用账号/项目/编辑器/素材隔离，包含区域、核对后的原文、替换和选择；关闭、刷新可恢复。访问序号阻止A→B→A期间旧识别回执覆盖当前输入。
- 提交前落盘本次草稿，再生成和上传实际PNG蒙版：修改区域透明、区域外不透明。沿用现有inpaint命令、原请求恢复和选区外RGBA保护；未知结果期间锁定文字与范围，同一次重试复用原蒙版与命令。
- 参数区独立滚动，生成入口固定；手机输入16px，支持320×568短屏。无请求时不新增轮询。

这仍是生成式图片文字修改，尚未提供可编辑字体图层、确定性排字或生成效果实时预览。生成后用户应核对字形、版式和内容。

## 接口与业务约束

新增`POST /design-assets/:id/text-regions`，沿用素材编辑权限；每用户每分钟最多10次，返回private/no-store。读取私有文件后使用Sharp正向化到sRGB PNG，图片单边最多2048px、解码最多4000万像素、归一化PNG最多8MB。复用现有AMUX Claude结构化JSON客户端，不新增独立供应商链路。

接口返回区域和归一化PNG的SHA256 `sourceHash`。读取缓存、共享识别请求或模型响应后重新核对权限与素材URL；每进程按用户/素材/哈希缓存10分钟，最多128项，同时最多8个不同识别请求。严格schema校验转录、数量与坐标；图片内文字只作为转录数据，不作为指令。

共享文字编辑契约仅允许实际masked inpaint/edit提交。任务运行时在参数校验前生成有界文字指令，单独指令最多3600字符、总提示词仍受4000字符限制。实际像素矩形统一由`imageTextPixelRect`取整，避免前端蒙版与任务说明使用不同边界。

本轮没有数据库迁移、新任务调度或状态副本。

## 独立性能采样

交互上下文重构后的单独测量通过：100个白板对象保留在图片工作区后方，包括30张图片、60张便签、10张色卡；原图600×800。原生时钟及rAF，每项30秒，不记录trace或video，不调用生成。环境为Windows、无头Chromium 145.0.7632.6、DPR1、浏览器报告16线程；记录时间为`2026-11-09T14:32:50.220Z`。

| 样本 | 平均fps | 超33.3ms帧占比 | 输入到下一rAF的P95 |
| --- | ---: | ---: | ---: |
| 静止 | 60.00 | 0% | 无输入 |
| 移动选区 | 59.97 | 0% | 1.5ms |
| 调整选区大小 | 60.00 | 0% | 1.4ms |

三个样本均达到平均至少58fps、超33.3ms少于1%的既定门槛。此为一项性能测试中的三个样本，不算三次功能测试；输入到rAF并非实体显示器端到端延迟，也不包含识别网络或模型生成时间。

## 尚未验证的边界

- 未调用真实收费模型，未测OCR准确率、中文/复杂字体、长文案排版、字形一致性或真实生成的样式保持。
- 未实现语义元素自动拆层、独立字体图层、字体选择/字距/旋转排版控件或细节增强。
- OCR缓存与共享请求只在当前进程有效，不是持久化幂等记录；进程重启后的识别重试可能重新调用供应商。
- 前端暂未用`sourceHash`独立检测相同尺寸素材被外部覆盖。正常编辑创建不可变新版本；若绕过版本链路覆盖文件或原URL，需要额外源图一致性保护。
- 没有实体手机、实际显示刷新链路或完整独立深色主题验收。
