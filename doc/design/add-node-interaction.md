## 添加节点与添加资源

用户选择：文本节点模仿LibTV；视频目前只提供导入和播放，接入生成API后再加入创作草稿；图片初始画幅为16:9。不新增备注功能。

底栏上传入口已改为“添加节点”加号，菜单分组如下：

| 分组 | 入口 | 当前行为 |
| --- | --- | --- |
| 添加节点 | 文本 | 空文本节点提供自行编写和AI起草。手动编辑使用可换行正文与明确保存；AI起草使用文字要求与明确参考，不出现图片尺寸参数。 |
| 添加节点 | 图片 | 创建上述16:9空创作目标，自动打开创作框，结果保留在同一目标及其版本历史中。 |
| 添加节点 | 视频 | 只导入已有视频，显示播放与实际媒体信息；不显示模型、生成时长或不可用的生成按钮。 |
| 添加资源 | 上传 | 导入实际图片/视频并放到画布，不自动提交创作。 |
| 添加资源 | 从已有资源选择 | 搜索、按类型筛选本项目素材与生成文件；尚未摆放的资料放上画布，已存在的资料直接定位，保留来源身份。 |

全局资源上传负责把素材放上画布；创作框上传负责给当前目标添加参考。两种行为需要保持明确，不能按当前选中图片偷偷推断全局上传的用途。

推荐功能只打开对应配置或素材选择，不执行任务。推荐项来自实际能力，不能把LibTV的高清放大、音乐、首尾帧生成等尚未接入能力复制成可用入口。

## 文本、视频与连线

文本编辑区位于节点内，正文按屏幕字号显示；Ctrl+Enter保存，组合输入和结束后的伴生按键不会误保存。未保存文字仍属于账号/项目/目标隔离的本机草稿，不写入共享tldraw快照。保存产生真实`reference_text`成果与历史版本，不调用模型；切到AI或采用历史前先保留当前已修改正文。保存回执未确认时显示“确认上次文本保存”，确认旧操作不覆盖后来编辑的内容。

AI起草通过`generate_text`复用现有文本模型和工作流执行记录。要求、明确图片和文本引用进入本次请求；不补入旧用途标签或权重，不启动图片任务。输出在同一目标形成版本，可继续手动修改、预览历史、采用旧版本或连接给后续创作。图片按实际传入顺序编号为“图N”，文字等其他引用显示“素材N”，同名素材仍以实际ID区分。

视频上传接受MP4、WebM，最大100MB。服务端核对存储对象大小、MIME、校验值和容器签名，私有读取经项目权限校验并支持Range；视频无需图片缩略图任务。画布中点击播放，提供实际尺寸/时长与放大播放；不支持浏览器解码的文件显示失败及重试。切换、隐藏、离屏和其他媒体开始播放时暂停。视频目标不显示创作提示词、模型或生成参数；当前模型不接受视频参考，输出端口显示禁用原因。

空图片和空文本节点也显示右侧连接入口。尚未生成时，连线只绑定目标身份；执行下游时检查上游真实结果并冻结准确版本。没有结果或文本尚未保存时阻止执行。已经锁定结果的输入不会随上游后来重跑而改变。连接开关仍只隐藏线和端口，素材和输入保留。手机新建和导入时只调整相机，使节点及两侧连接入口进入视野，不改变素材的世界坐标或尺寸。

导入命令与填入视频目标分两步确认，均沿用原mutationId。未知回执不会重复上传、创建媒体或追加版本；关闭资源窗口后仍可从画布恢复待确认导入。只读成员可查看和播放，但不能新建、导入或修改。
