## 本轮方向

用户明确改用非 Live2D 路线，舍弃旧人物造型和旧素材。基于本轮提供的森林布偶参考图提取森林、织物、温暖与手工感，重新设计为简单几何构成的智能助手。旧版 v8 母图冻结、72 层、17 参数及 Cubism 交付要求不再适用于本方案。

原图和视频仅用于设计研究。新形象使用独立绘制的矢量轮廓、叶片、眼睛、嘴、缝线和道具，不包含 DS 鲸鱼娘或其他角色的模型、纹理、动作文件。研究视频中的产品能力文案不构成当前平台功能需求。

互动延续本轮前已经确认的方向：桌面优先、手机适配；鼠标目光跟随、悬停回应、轻点展开现有聊天、长按拖动、松手回弹；与真实设计任务状态联动；活泼但不抢注意。聊天展开时隐藏角色，收起时恢复。

## 样稿阶段的建议实现路线（历史）

使用 React 外壳、单份内联 SVG、CSS/原生 Web Animations API，以及少量直接更新元素的 JavaScript。项目已有交互与任务状态链路可复用，不新增动画引擎，不再加载 Cubism。动画自身不调用云端推理；原有 AI 服务的使用成本仍由原业务决定。

1. 定稿形象：以 48、72、96 px 和放大视图核对轮廓与眼睛；将可复用 SVG、色板、静态表情和状态说明冻结为一版。
2. 固定动作内核：建立常驻生命感、表情、姿态、道具四层；每层单独驱动，防止呼吸、拖动和动作写入同一 transform 相互覆盖。定时动作使用原生动画，连续跟随用少量数值插值；旋转、位移和缩放为主，不持续重算复杂路径。
3. 迁移交互外壳：保留 400 ms 长按、6 px 位移阈值、直接跟手的位置变化、越界限制、取消回原位、账号/项目位置记忆与键盘打开助手。悬停回应冷却设为 8 秒，后台或聊天展开暂停；恢复不补播历史动作。
4. 接入真实状态：由现有会话事件和工作流节点状态生成统一的展示状态，复用现有请求，不给角色单独增加轮询。处理中进入思考或创作，成功时短暂庆祝，失败或待确认时疑惑，取消则平静回到陪伴。网络读取失败不推断业务失败。
5. 完成真实工作台验收后切换入口，旧模型和导出产物作为历史资料排除出新版加载路径；不在设计提案阶段删除旧历史文件或发布到生产。

### 状态与控制约定

前端展示状态采用 `idle | thinking | working | success | needs_attention | sleeping`。悬停、拖动、放下和聊天显隐是独立交互事件，不冒充任务状态。

优先级为隐藏/减弱动态 > 拖动与放下 > 新任务结果提示 > 思考/创作 > 悬停 > 待机。任务持续时不因悬停退出工作状态；打断动作从当下姿态过渡，不复位再播放。新状态生效时取消旧的自动返回计时，避免任务已经开始却被旧动画拉回 idle。

按项目、会话和任务标识隔离事件。历史加载只设置当前状态，不播放庆祝；同一终态只响应一次；关闭聊天后根据当前任务状态恢复，不连播隐藏期间的事件。多任务同时到达合并为一次反馈，结束后回到是否仍有任务运行所决定的状态。

第一阶段只映射既有平台状态，不新增语音聊天、音乐陪伴、电脑操作、摄像头或自主任务能力。视频在本轮只提供造型与动态灵感。

### 动作初始调校值

- 待机呼吸约 4.8 秒一周期，主体缩放约 1%，位置变化不超过角色宽度的 1%；眨眼间隔随机 3.2–5.2 秒。
- 目光跟随限制为局部微移，主体倾斜更小；快速输入被平滑处理，停止输入后自然归位。触屏取消被动鼠标跟随。
- 表情切换约 160–180 ms；普通姿态切换约 240 ms；打招呼和成功演出约 700 ms，整体反馈在约 2 秒内结束。
- 长按提起轻微纵向拉伸，外部位置直接跟手；松手约 420 ms 回弹，保持角色落点。
- 创作只让小画笔轻轻转动，稿本保持稳定；任务忙碌不使用永不结束的大幅旋转或假进度。

以上为样稿调校起点，正式接入按真实尺寸与工作台负载验证。

## 样稿阶段的验证记录与验收目标（历史）

本轮浏览器检查通过：六种按钮状态切换、长按进入拖动、80 px 横向拖动、松手回待机、打开聊天时隐藏与收起恢复；减弱动态下运行中动画数为零；320 px 与 375 px 视口无横向溢出，移动端状态按钮高度为 44 px；交互检查未发现页面脚本错误。完成明暗主题截图检查。

检查未覆盖正式任务事件、现有聊天后端、持久化位置、长时间硬件性能；原型通过不代表生产验收。

正式接入后重点验收：

- 所有状态在正常速度和慢放下切换连续；完成反馈中立即长按、拖动中取消、切换项目、隐藏/恢复均不跳变。
- 真实任务处理中、成功、失败、待确认、取消、重试、历史恢复和重复事件均显示真实状态；角色不会触发生成或消费。
- 60 Hz 桌面目标平均帧率至少 58，超过 33.3 ms 的帧间隔少于 1%；在含 100 个对象的代表性工作台测量 10 分钟，确认主任务和画布操作未受明显影响。数字是验收目标，本轮未测得。
- 320 px 手机宽度、触控长按、输入法与键盘弹出、暗色主题、减弱动态、失焦、越界、隐藏与卸载均能正确清理。
- 执行相关组件/状态测试、定向 lint 和类型检查，以及单 worker 浏览器验证；不主动运行完整检查、CI、提交或推送。
