# 画布到助手的多素材引用验证

日期：2026-11-09（北京时间）。接续图片编辑，完善画布选择、明确引用、对话草稿与实际发送的一致性。沿用森织的暖白深绿和同一聊天，不增加模型调用。

## 修复与界面

- 普通选择、取消选择和定位只改变画布选中对象。点击“引用到助手”才追加素材；不会替换已选面料或其他参考，也不会自动发送或创建对话。
- 点击时捕获当前对象，再等待素材与布局保存。准备期间按钮显示“正在准备引用…”，发送暂时禁用；保存失败保留原草稿与引用。之后改变画布选择不会把这次引用换成另一批。
- 页面刚刷新时，先恢复原对话的本机草稿，再处理待加入的引用；恢复期间输入与发送暂不可操作。明确的键盘/鼠标打开请求在恢复后继续聚焦，触屏不主动唤起软键盘。
- 显式引用和正文 `@` 引用一起计入 16 项上限，稳定去重，合并超限整体拒绝，不静默截断。旧引用失效时保留提醒并阻止发送，新增引用不会掩盖问题；只读对话不能添加引用。
- 引用区独立占一行，显示数量、完整比例缩略图、名称、素材类型、定位与移除。超过两行内部滚动；手机移除按钮至少 44px。同名素材按创建时间与ID排序编号，选择器和输入区使用同一称呼；提交仍使用对象ID。编号不是永久业务标识，同名对象集合变化时可能变化。
- 图片加载失败提供素材类型占位；更换预览URL后可重新加载。长名称省略但定位按钮保留完整提示和无障碍名称。
- 画布副本对应关系属于当前对话草稿，按账号、项目和会话恢复。后续选中别的对象不覆盖此前引用的副本；删除放置时仍可引用已有业务素材。
- 已被执行消耗的素材再次编辑可能产生新ID。发送前若检测到引用指向新版本，先更新预览、保留正文并提示再次核对，不在同一次点击中悄悄提交不同素材。
- 未知发送结果重试复用完整请求键；正文、引用、讨论范围或提案发生变化时使用新请求编号。原先只按正文复用编号的问题已移除。

未更改后端任务契约、供应商参数和图片生成服务。手动设计工具同样保留打开时所选的放置关系，避免借用另一份聊天的引用。

## 验证记录

最初以实际浏览器复现三项失败：普通选择自动加入引用、追加覆盖原引用、改变素材却复用原发送编号。失败截图与trace保存在 `output/playwright/canvas-assistant-references/before/`。

已执行 51 项不同前端单元检查：引用解析与合并16、引用选择器4、光标提及输入5、画布放置与视野4、对话上下文10、持久草稿12。Web类型检查和相关源码ESLint通过。

本轮浏览器用例覆盖：普通选择、连续追加、光标和实例保留、重复引用、请求重试、16项合并上限、保存失败和延迟、只读、失效引用、1440px/320px同名素材、刷新恢复、发送载荷、系统深色偏好下的短屏/长名称/缩略图失败，以及副本编辑分支。平台仍采用现行暖白主题，这不是新增深色主题。原有保存中继续编辑、画布视野保持、手绘选择回归同时检查。

浏览器是受控接口夹具，不执行真实模型请求。副本分支测试模拟服务端新ID规则；真实数据库中的冻结和副本规则沿用 `canvas.service.integration.spec.ts` 的独立验证，本轮不将历史记录计为新增通过数。

测试排查记录：错误提示含关闭按钮，初轮精确文本定位改为按alert内容查找；44px小数布局按0.001px浮点误差检查。旧保存用例仍等待常驻“已保存”，改为核对真实保存内容后确认提示消失；副本测试改为捕获具体shape ID，避免把DOM顺序误当对象身份。

新增冷启动测试确实复现了旧草稿尚未载入时，新引用导致正文无法自动恢复的问题。持久草稿新增就绪状态，引用等待恢复后再合并，修复后同一用例通过。失败证据保存在 `hydration-before/`。

一次过宽的旧回归筛选同时命中了工具参数、系列配色和旧直接生成路径，出现未通过后停止该批次；不把该批次算为通过。后续单独核查确认：工具参数与生成用例仍假定助手默认展开，系列用例直接寻找已经移入项目菜单的按钮。测试明确保存“助手展开”的返回用户偏好，系列先打开项目菜单；相关业务代码没有修改。工具草稿、系列配色、桌面1280px与手机375px的确认生成恢复四项在 `legacy-recheck/` 中全部通过。生成用例由受控回复给出确认方案，不证明真实模型会如何判定直接执行意图。

最终共有26项不同功能浏览器用例分批通过：新增多素材引用11项、白板恢复4项、既有工作流聊天7项，以及上述单独核查的4项。最终界面一批12/12通过，覆盖新增11项及旧聊天视图切换；旧用例已改为回到设计工作台打开助手，再切回流程视图，不依赖已移除的流程视图助手入口。为录屏复跑的桌面与320px两项均通过，不重复计入26项。

相关源码和测试文件ESLint、Web类型检查、`git diff --check`通过。完整旧浏览器套件未运行，不将定向通过扩展为全套回归结论。
