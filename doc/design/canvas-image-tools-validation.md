# 画布图片快捷工具与编辑连续性验收

日期：2026-11-10。本轮将已有图片工具接到白板所选对象操作区，减少从作品到编辑参数的往返，保持森织暖白/深绿与织芽形象。参考方向来自已保存的Lovart公开画布说明：选中对象后可访问相关图片操作；未把公开说明等同于其内部效果实测。

## 界面与操作

- 单选已关联候选资产且可编辑的图片时，显示“图片工具”菜单：局部重绘、移除背景、擦除、裁剪图片、扩展画面、旋转与翻转、色彩与明暗、修改文字、生成变体。复用现有菜单、图片工作区及执行链路，打开入口不创建会话、不上传蒙版、不扫描文字、不提交生成请求。
- 锁定、隐藏、多选、只读及无有效候选关联时不提供快捷编辑；点击时再次核对当前选中对象和资产身份。菜单期间图片关联变化会关闭旧菜单，不将旧操作带到新图。
- 只在有多选时显示分组操作，有分组时显示解除分组；图片历史、引用和详情继续保留。菜单沿用键盘上下选择、Escape与原生触控滚动。手机按已有自适应规则使用浮层或抽屉。
- 入口只选择对应编辑方式，不改变方向、色彩、扩图或局部选区草稿。关闭返回图片工具按钮，不新建另一份编辑器。裁剪首次依据原图尺寸初始化；再次打开保留本次裁剪范围。
- 明确入口在原草稿初始化后处理，每次带资产身份和递增编号；关闭、切换或读取取消后不补执行过时入口。普通详情打开继续保留此前模式。
- 未确认的一般图片命令、局部重绘命令或版本恢复优先于新编辑入口。快捷菜单会展示原操作/续办说明，既有操作结束后不会突然切到早先点击的工具。

## 只读与草稿保护

图片工作区接收实际可编辑状态。只读时保留预览、缩放、原图下载、历史比较与来源读取，隐藏编辑工具、分享写入、款式保存及恢复入口；保存和提交函数同时检查可编辑状态。来源面板中的设计路径也使用只读模式。

权限撤销立即回到查看，保留草稿；恢复权限后继续同一图片草稿。图片内容基线以不可变资产ID为准，权限变化单独控制操作，不再制造假内容冲突。真正的资产变更仍受原冲突边界保护。图片冲突时禁止写入但不禁用整个窗口的关闭和预览。服务端权限仍为最终边界，本次是前端呈现修正，未新增后端授权规则。

补查发现方向草稿关闭后立即刷新可能丢失最后一次角度变化；关闭现在先checkpoint方向草稿，成功提交后的方向复位也同步保存。实测立即关闭/刷新保留90°，完成保存后再刷新为0°，不重复应用已完成调整。

中文输入法组合输入期间Escape不退出工具或关闭外层详情；普通Escape继续保留原返回规则。这里只验证浏览器组合输入事件，未声称实体中文输入法候选窗实测。

## 画面检查与修复记录

1. 首轮部分测试将隐藏的旧页签当作入口，或使用不准确标签，修正测试定位后验证实际内容。菜单键盘开合实际正常；多选检查需在解锁清除选择后重新选中图片。
2. 未确认操作的提示曾被原错误文字覆盖，现明确显示续办说明，原请求继续保留。
3. 手机全屏编辑器被一般窄屏规则覆盖为8px外边距，底部工具栏阴影在三边被裁切。提高全屏规则优先级并为手机工具栏使用较小的现有阴影后，默认/悬停/菜单展开/编辑稳定四态检查均cut=0、hidden=0。
4. 权限恢复后的假内容冲突和立即关闭后方向草稿丢失均由浏览器复现并修复；初始失败截图/trace保留在下述目录。

证据目录 `output/playwright/canvas-image-tools/`：

- `selected-*`、`menu-*`、`rotate-*`、`adjust-*` PNG，桌面与320px实际截图。
- `tour-1440.webm`、`tour-320.webm`：打开菜单、进入旋转、返回并切换明暗的录屏，不发送生成请求。
- `clip-1440.json`、`clip-320.json`：四态结果。扫描范围为所选操作区、菜单、编辑器后代；菜单自身另查视口边界，不声称扫描了根菜单投影。
- `initial-failures/`：初始失败证据；`performance.json`：原始帧间隔和输入采样。

图片沿用仓库 `prototype-assets/impeccable` 已有原型素材，未重新生图。320px检查启用触摸模拟、系统暗色偏好和减弱动态；平台仍为现行浅色主题，不代表完整暗色皮肤或实体设备验收。

## 性能

2026-11-10北京时间14:24，Windows、Chromium145.0.7632.6，无头、DPR=1、16逻辑线程。100对象保留挂载，原生时钟/rAF、单worker，无trace/录屏/并行检查；本地受控接口、600×800图片。三段各30秒，菜单共打开31次：

| 场景 | 平均fps | >33.3ms帧 | 输入至下一帧P95 |
| --- | ---: | ---: | ---: |
| 图片工具菜单反复开合 | 59.97 | 0.056% | 13.8ms |
| 拖动旋转预览 | 59.27 | 0.225% | 11.0ms |
| 返回白板平移 | 59.97 | 0.056% | 7.7ms |

均达到≥58fps、长帧<1%的目标。从点击旋转菜单项到控件可用815ms，包含本机初始化及界面转换，并非纯网络或显示器延迟。输入指标是事件至下一次rAF，不能等同真实屏幕呈现。方向关闭checkpoint是在此测量后补充，只改变关闭/提交时的草稿落盘，不重测或扩称其延迟。
