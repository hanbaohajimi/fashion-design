# 画布总览导航验收

日期：2026-11-10。补充大画布的总览定位能力，沿用森织暖白深绿与已接入的毛绒织芽。

## 使用与行为

入口为无限白板底部“更多白板操作 → 画布总览”。总览浮在工具栏上方，显示可见对象的简化轮廓、当前视野边框、对象数量与缩放比例。它与对象目录互斥，默认关闭，关闭不移动视野。

- 点击当前视野以外的区域可跳转；拖动视野框保持抓取偏移和原缩放。拖动过程中固定坐标映射，避免总览随着移动改变比例、造成指针漂移。
- Escape取消当前拖动并恢复开始前视野，再按一次关闭总览。触控取消、失焦、离屏和卸载同样结束未完成手势。松手提交最终视野，沿用现有账号/项目视野偏好保存。
- 键盘方向键平移，Shift增加步长，Home查看全图，加减键缩放，0恢复原始比例；关闭后焦点回到更多操作入口。中文组合输入不会误触发Escape。
- 总览只改变视野，保留对象选择、当前绘图工具和聊天草稿。双击总览不会打开所选素材详情；绘图工具下拖动总览不会生成笔画。
- 隐藏对象和隐藏父级的后代不参与总览，普通分组没有独立外框占位；画框裁切后的范围参与绘制。选中分组时高亮其可见后代。只读项目仍可导航。
- 320×568与320×400保留44px触控按钮，短屏临时隐藏重复的视图切换。手机打开总览时暂停织芽，关闭恢复；桌面默认角色位置与总览分别位于右侧与左侧。
- 总览属于界面层，不进入文档保存或导出。打开总览并改变视野后，实际下载的混合画布PNG与打开前逐字节一致。

## 实现与生命周期

总览使用二维canvas绘制简化对象矩形。可见对象几何单独缓存，相机变化只更新总览与视野框；React面板和关闭回调保持稳定。描画与拖动更新通过独立的requestAnimationFrame合并，无持续空转循环、额外接口或模型调用。

背景、离屏、关闭、切换流程视图及卸载时停止绘制并清理响应订阅、观察器、监听和待执行帧。绘图环境不可用时显示明确提示，保留全图、缩放和关闭入口，不展示虚假的加载进度。

未直接使用当前安装版本的DefaultMinimap：检查其实现后确认内部形状路径收集没有套用本平台隐藏过滤，且现成canvas交互未包含本轮键盘与取消契约。本实现使用同一Editor的公开几何、相机、响应订阅接口，没有更换白板组件或维护第二份业务文档。

## 检查证据

- 4项坐标单元测试通过，涵盖负坐标、作品与视野共同范围、指针限位、空白/异常尺寸，以及隐藏与分组过滤。
- 12项总览浏览器用例分批通过：聊天与视野连续性、点击和拖动取消、显隐、双击/绘图隔离、分组、绘制生命周期、故障回退、实际导出、只读有内容/空白、两种触控高度。
- 10项现有功能回归通过：旧图片比例恢复、权限变化、320px比例操作，对象目录开合、层级、桌面/窄屏长名称、八层分组、两种高度的触控。
- Web类型检查与8个相关目标文件ESLint通过。根目录ESLint的既有Next pages路径提示仍存在，退出码为0。
- 所有浏览器检查使用单worker。API采用受控响应，不证明真实数据库或模型效果；后台可见性检查通过模拟visibility事件，触控使用Chromium原生触控派发，仍需实体设备验证。

生命周期用例记录实际fillRect调用：静止时不持续增加，离屏/后台不继续绘制，关闭后操作画布不再触发旧总览绘制；反复开合后单次相机变化没有累积绘制。取消场景检查实际画布视野，其他导航检查也核对真实素材的屏幕位置。

## 100对象独立性能测量

数据为 `output/playwright/canvas-overview/performance.json`，时间 `2026-11-10T02:56:42.597Z`（北京时间10:56）。Windows、无头Chromium 145.0.7632.6、DPR 1、16逻辑线程；100对象包含30图片、60便签、10色卡，织芽持续陪伴。原生时钟和rAF，三种状态各连续操作30秒，无trace、录屏、CPU采样或其他检查并行。

| 状态 | 平均帧率 | 超过33.3ms的帧 | 指针事件至下一帧P95 |
| --- | ---: | ---: | ---: |
| 总览关闭，平移画布 | 59.94 fps | 0.111% | 6.3 ms |
| 总览打开，平移画布 | 59.90 fps | 0.167% | 5.0 ms |
| 拖动总览视野框 | 59.74 fps | 0.335% | 2.4 ms |

三种状态均达到平均至少58fps、长帧少于1%的目标。该测量是受控开发页面的帧间隔与下一帧响应，不代表实际屏幕端到端延迟、生产构建、实体手机或真实高分辨率文件负载。最后仅补充缩放读数的`aria-live="off"`，避免辅助技术在拖动缩放期间反复播报，不改变绘制与事件路径。

复测设置`OVERVIEW_PERF=1`，运行`pnpm exec playwright test tests/e2e/canvas-overview-performance.spec.ts --workers=1`。画面证明使用忽略目录的`output/playwright/canvas-overview-proof.config.ts`。
