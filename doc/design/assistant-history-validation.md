# 长会话与历史访问验证

日期：2026-11-09（北京时间）。接续多素材引用，完善长期使用中的历史查找、会话链接、旧消息阅读与草稿连续性。保留现行暖白、深绿和织芽形象。

## 行为与实现

- 历史列表保留首批50条，提供“读取更早对话”，追加去重并显示已载入数量。读取失败原地重试，不清空当前对话或正文；沿用可搜索的现有选择控件，其搜索范围为已载入的对话。
- 会话链接不受首批列表限制。新增 `GET /projects/:projectId/agent-conversations/:conversationId`，直接读取该项目、当前账号创建、尚未归档的指定会话。链接不存在、属于其他项目/账号或已归档时明确报错，不静默改开最近一条。
- 失效链接可从历史列表选择其他对话，或主动新建；选择后同步链接中的会话标识，刷新不会再次回到失效目标。旧版会话继续只读。
- “读取更早消息”独立于首次加载，输入、发送与当前草稿不因翻页重新初始化。同步请求使用取消信号与会话代次，旧响应在切换、重新选择和卸载后不写入其他会话。
- 旧页与最新轮询按消息ID合并：旧时间戳和pending回执不能回退已确认状态，过期pending确认卡不能复活。重复页保留顺序且去重。
- 当前工作区在内存中保留最近8段会话已展开的消息页和游标；切回这些会话继续从阅读位置查看。账号或项目工作区重建时释放。刷新仍按服务端分页重新读取，未新增整段聊天的本机持久化。
- 回看历史显示“回到最新”；真实新回复或已观察的任务结果变化才显示“有新消息”。刚加载的旧确认卡建立基线，不算新结果。提示浮在阅读区内，不改变列表高度；点击后滚到最新并将键盘焦点留在对话区域。
- 阅读区域可键盘聚焦，支持Home等原生滚动；用消息身份和相对位置补偿历史插入、分栏、窄屏切换。被移除的消息停止尺寸监听，卸载清理绘制回调。未添加常驻逐帧更新。

接口无需迁移，沿用已有权限与数据库记录；不触发模型、生成或新任务。部署时需包含该API读接口与对应前端，但本轮没有部署。

## 缺陷复现与修复证据

初始浏览器测试确实复现两项失败：没有第50条之后的历史入口、旧会话链接误开最近会话。证据在 `output/playwright/assistant-history/before/`。初次慢读取测试曾等待较长时间，可能被正常轮询解除全局loading掩盖；后来把准备期间可编辑断言限定在400ms，不将最初通过作为旧实现正确的证明。

补充带已拒绝确认卡的旧页后，复现历史加载误报“有新消息”，失败记录在 `proposal-before/`，修复后桌面和320px通过。

键盘Home测试复现回看停在中间：提示按钮参与布局导致阅读区高度改变，干扰原生滚动。稳定等待消息和输入就绪后仍复现（`keyboard-baseline/`）；将提示置于不占位浮层后，原用例与桌面/窄屏追加历史均通过（`keyboard-after/`）。

失效链接测试初次使用精确文本定位，没有匹配包含重试按钮的提示容器；截图已证明错误文案存在，改为按alert内容查找。没有为测试修改业务错误文案。
