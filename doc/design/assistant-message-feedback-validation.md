# 设计助手消息与执行结果展示

更新：2026-11-15。范围为消息排版、执行反馈文案及支撑文案的已核实回执字段，复用现有执行、保存和恢复链路。

## 呈现规则

- 用户消息轻靠右，暖灰背景、0.5px边框，最大宽度为内容区90%；助手反馈靠左，可使用内容区全宽。
- 同轮相邻请求与反馈相距10px；不同轮次相距22px。绑定以 `replyToId` 为优先；已知后台消息不与无关请求拼成一轮。
- 已打开面料库使用一行“面料库已打开”及小型成功图标。多对象对齐、色卡、连接使用紧凑暖白结果块，0.5px边框、12px内距、10px圆角，无大面积绿色或阴影。
- 结果标题14px、600字重、深墨绿；范围和方式13px，采用现有清晰的次级文字色。结果数量与范围来自冻结对象和核实回执，不要求用户重读自己的请求。
- 参考连接展示“参考连接已建立”“上游探索 → 下游夹克”。第三行仅在回执核实后显示“尚未开始生成”或“本次未触发生成”。
- 失败／部分完成／进行中／结果待确认使用对应文字和不同图标，不能只靠颜色识别。普通聊天仍渲染正文，即使模型写了“已完成”，也不会自动变成成功结果卡。
- 长名称超过36个Unicode字符时紧凑省略，悬停或键盘聚焦可查看全名；长词允许换行，手机提示宽度保留视口余量。超过4项显示前三项及真实剩余数量。
- 保留已有、确有目标的查看结果动作；不增加重复打开面板、自动生成或缺少业务支持的撤销按钮。失败恢复继续使用原操作编号和“继续确认画布操作”。

## 真实状态与兼容性

新增共享 `AssistantCanvasResult` 展示事实契约，由原 `AssistantCanvasActionsService.finish` 核实对象签名、素材绑定或连接保存后写入原消息上下文。包含对应动作ID、对象名称、类型和连接目标；只有连接操作核实当前目标实际执行记录后才写入生成状态。

前端同时匹配动作ID、目标ID和来源对象，再使用展示事实。旧成功消息仍可从已有动作和观察快照展示结果、数量及名称，但不会补造生成状态。失败和未知回执不读取成功事实，也不把用户提出的“其他东西不要动”显示为已保证的结果。现有业务API、权限、幂等、数据库结构及历史原文保留。

新 `AssistantActionFeedback` 与 `assistant-action-feedback` 负责结果结构和文案；`assistant-message.module.css` 负责用户气泡及轮次间距，`WorkflowAssistantPanel` 按真实消息类型接入。已有 `creationActivity` 的部分完成与失败先展示明确状态，详细要求与可用成果仍可展开。

本阶段没有接入后来提供的StatusMark／ThoughtLine新源码；两个动效先单独讨论，现有思考行和动态图标继续沿用项目实现。

后续用户已确认采用“图标变化为主”的轻量方案；该接续阶段的StatusMark、ThoughtLine与真实状态交接单独记录在[状态动效验证](assistant-status-motion-validation.md)，不改变本阶段的排版与核实回执规则。

## 验证范围

证据位于忽略的 `output/assistant-message-feedback/`。

- 400×640默认浮窗及360／420px桌面浮窗、320px手机，分别检查对齐、面料库打开和连接结果，共12张主要截图。
- 实测同轮间距10px、用户气泡宽度不超过90%；标题14px／600，标题对比度至少14.12:1、次级文字至少6.28:1，均无横向溢出。
- 覆盖短屏长名称、全名键盘提示、失败、待确认转成功原位更新、部分完成展开、普通聊天及轮次间距。单worker Chromium的17项消息用例与11项原画布动作回归通过；最后的长名称与部分完成3项在样式精修后单独复测。
- 使用desktop-agent-ui附带clip-audit脚本检查消息父容器，以及长名称Tooltip的全页面／浮窗范围；静态、聚焦提示、展开、状态更新终态共19份回执，`cut=0`、`hidden=0`，保留为 `*-clip.json`。没有通过裁切根节点的方式忽略自身投影。
- Web定向Vitest两个文件25项，API定向Vitest四个文件59项；核实空目标与已有失败执行目标的生成文案、无回执不成功、失败不补造事实、目标匹配、原位更新、轮次关系和既有消息合并。
- Web/API类型检查和目标ESLint通过。真实PostgreSQL的原画布创建／连接／生成历史集成测试21项通过，并追加展示事实断言；Vitest合计105项。具体结果记录在同目录 `integration.log` 与汇总中。

浏览器使用隔离API夹具；本次不调用真实模型或生成图片。真实供应商的四项自然语言测试属于前一阶段，见[真实模型记录](assistant-canvas-real-validation.md)，不能计作本次新增反馈组件的模型验证。不触发CI，不提交或推送。
