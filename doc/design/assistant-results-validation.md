# 聊天执行结果回看与继续创作

日期：2026-11-10。本阶段补齐实际执行终态回执中的图片结果，减少“工具已经完成，但聊天里只有一句话，需要再去白板找图”的往返。保留森织独立视觉和现有白板、图片工作区、任务中心及款式交付链路。

同日后续已修复旧确认卡借用当前参数/输出的问题，并接入排队、实际处理与停止后核对；当前行为及独立证据见[执行与历史确认接续](assistant-execution-validation.md)。本阶段下文记录的“旧确认尚待核对”是当时边界，不能覆盖后续接续事实。

## 实际行为

- 新执行的事实回执显示本次真实图片，按尝试顺序排列，包含图片名称和桌面尺寸信息。缩略图完整contain，按需加载；读取失败可以重新加载，不将缩略图故障误报为任务生成失败。
- 点击图片直接进入该资产的现有图片工作区。继续修改只追加该图片到当前聊天引用，保留正文和已有引用，明确发送后才提交下一条需求；浏览、比较和追加本身不执行生成。
- 多图结果可直接“比较本次结果”，复用原图片比较器，桌面并排、手机切换图片；比较只限这次结果。关闭回到原比较入口，保持草稿和聊天实例。
- 部分失败显示已经完成的图片，并分别说明未完成或取消的操作数。没有图片的取消、技术失败和分析结果不构造图片卡片，也不播放成功反馈。
- 已移除节点或同一节点换成另一张图时，旧回执仍按原资产回看，不打开替换后的图片、不把新图当原图引用；提供项目生成文件入口继续使用现有明确放回画布流程。仍有准确候选节点时可以继续原有图片编辑。
- 执行结果不展示与本轮无关的“未保存引用记录”常驻提示；普通回复的引用记录继续保留。旧确认卡仍提供原来的查看结果入口，新的事实回执提供本次图片画廊，不声称旧卡的当前图连接代表不可变批次。

## 结果归属与兼容

共享契约新增 `WorkflowExecutionResult`，记录执行ID、工具节点、明确终态、完成时间、完成/未完成/取消尝试数，以及真实图片资产ID、当时节点ID、标题和尺寸。记录不含签名URL或客户端提供的图片地址。

新事实回执在持久化时固定本次结果身份。结果来源为该执行的真实 `WorkflowAttempt`、对应成功的 `GenerationTask.output.images` 或 `ImageTransformResult`，再复核图片资产属于项目且与生成任务匹配；排除内部探针、蒙版等非作品资产。不从工具节点当前连接的全部图片猜测，不混入后来重试或其他批次，不用模型文字作为成功证据。

消息读取对没有有效结果摘要的旧事实回执按项目/会话/创建者和真实执行恢复，按页批量读取；不回写旧消息、不新增轮询、不调用模型。新摘要与原消息的executionId不一致时不展示，旧格式和不含图片的结果继续按原消息阅读。原HTTP权限、分页与只读成员自身历史访问保持，不能借会话中的外来executionId读取另一人的执行。

后端文案改为已验证的完成、部分完成、取消或失败，不再固定承诺“正在结合结果整理建议”；后台分析仍独立运行，分析失败不会撤回真实图片，也不自动重试生成。无需数据库迁移，API、shared与Web应一同发布。

## 手机空间与交互

截图复核发现，原会话标题和四个文字按钮占用多行，挤压结果阅读区。本轮改成标题与四个图标入口的一行工具栏，保留可访问名称和原有操作；移动触控按钮44px。较长标题省略显示，不撑开整个侧栏。

输入区省去手机上重复的视觉标签，输入框的可访问名称保持；无明确引用时，当前讨论对象使用一行文字，不再占整块着色区域。执行说明压缩为“讨论不生图，明确要求生成或修改时执行。”，保留真实影响范围。手机结果缩略图使用120px高度，尺寸元数据收起，名称和继续修改动作保留；较长消息仍可独立滚动，不挤走正文与发送操作。
