# 设计助手任务归并与图片名称统一

日期：2026-11-15。

## 用户确认的范围

普通图片不再普遍称为候选图；同一次任务的进度与结果合并，保存等无关记录退出聊天主线。图片生成完成后显示适中预览、一句说明与“查看画布”，保留原功能、数据和历史记录。

## 实现

- `assistant-transcript.ts` 从原消息生成展示行。只按会话内的执行编号聚合；未带执行编号的提交可凭确切创建目标与运行记录关联，不按名称或相邻时间猜测。重跑、交错任务和不同会话保留独立，普通讨论、澄清和方案确认维持各自语义。
- `AssistantTaskMessage` 统一呈现进度、真实成果和异常。一次任务保持同一位置，提交说明和完成回执集中到“查看过程”。失败事件不会因名称为completed而显示成功，未知提交回执仅提供重新读取；停止沿用原任务编号，状态核实后才显示取消。
- 图片预览完整contain，最大240px宽、300px高，点击可查看准确原图；默认主操作为“查看画布”。继续修改、放大和多图比较保留。临时定位不改变选中对象或草稿，手机返回恢复原聊天；无法找到确切历史图时提示，不使用同目标的新版本替代。
- 打开面板、移动、对齐等轻量动作紧凑呈现；色卡和参考连接保持结构化信息。部分完成与失败优先提示，已获得的图片仍可访问。
- 新手动文本保存、视频导入和资料关联不向聊天写保存回执，也不为了手动保存新建会话；对应CanvasCreationRun、资源修订和画布保存继续执行。有实际异步任务且明确绑定会话的领域记录仍可提供任务反馈。
- 已有AgentMessage未删除或改写。普通保存和版本采用记录从“助手设置 → 画布操作记录”查看，可继续读取旧页。任务详细原文仍可展开；现有版本、幂等编号、资产引用与权限校验继续沿用。
- 普通图片的按钮、数量标签、空状态和错误提示改为图片／设计图，主动比较称方案。新生成默认标题使用“生成图”；旧自动标题在显示层转换，原始名称和用户正文保留。内部candidate字段、端口及数据关系保持兼容，不迁移数据库。

## 验证

定向单元测试覆盖同任务归并、精确关联、交错执行、分页终态保护、异常、未知回执、原始记录不变、旧自动标题，以及原款式和展示包功能。真实PostgreSQL测试使用临时测试项目，核实保存版本、旧消息保留、新保存不新增回复、结果读取绑定和失败／未知回执。

浏览器使用隔离接口与测试图片，覆盖1440px桌面和390px／320px手机的排队转完成、预览比例、停止及部分停止失败、旧历史、重跑、比较和继续修改、图片替换后的准确原图、操作层级以及草稿保留。截图在忽略目录 `output/assistant-task-transcript/`；轻量动作截图在 `output/assistant-message-feedback/`。

验证不调用付费模型，不将浏览器或数据库夹具视为真实模型、队列和私有存储的全链路验收。没有数据库迁移，未触发CI、提交或推送。
