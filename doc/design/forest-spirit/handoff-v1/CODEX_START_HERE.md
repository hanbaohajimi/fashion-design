# 交给 Codex 的执行任务

## 目标与边界

在当前服装设计系统中接入一只真实的 Live2D 森林布偶设计助手。当前任务是精确复现已经确认的形象并实现交互，**不是重新设计角色**。

先完整读取本包 `README.md`、`docs/01_visual_lock.md` 至 `docs/07_official_sources.md`，以及 `specs/` 下的规格文件；直接查看 `references/00_approved_board.png` 及面部、靴子、工具袋裁图。不要只读取文件名后凭想象绘制。

## 最重要的限制

- 唯一角色基准是最后确认的浅金头发、棕色绣眼、棕色短靴角色。早期红发娃娃及其照片不在本包中，不得补入。
- **仅无睫毛**是强约束，所有睁眼、闭眼与动作帧均须满足。不要因此顺手更换眼色、脸型、嘴形或发色。
- 保留当前帽子、披肩、围巾、靴子和缝纫工具袋，不按此前未采纳的建议改成叶冠、种子、兔子或其他轮廓。
- 参考裁图含背景，不是生产图层；小视图不是严格正交图；无法从单张图恢复被遮住的像素，应明确补画及审核需求。
- 不允许用一个 PNG 的 CSS 平移、旋转、缩放冒充完成 Live2D。
- 不允许编写空 `.moc3`、假 PSD、无效模型 JSON 或伪造测试通过。

## 已确认交互

1. 光标进入有效角色区域，播放一次轻抬头、扶帽檐的动作；停留不循环、连续进出不排队。
2. 左键短按直接展开当前项目的现有完整对话框，精灵主体隐藏；不要等动作结束。
3. 长按后拖动，只在用户拖动时移动；松手不打开对话，不自主游走。
4. 收起对话恢复精灵位置。会话、草稿、参考素材和任务都延续，不再创建一套聊天。
5. 不加独立小面板、右键教学或额外按钮群；文字、语音和消息保留在原完整对话内。
6. 主动总结的业务规则尚未全部确定。只预留事件接口；默认不要对每次白板操作发提示，也不要自动启动收费生成。

## 执行顺序

### 阶段 A：仓库与资产审计

读取当前仓库的说明、依赖和相关组件。查清实际前端框架、画布方案、对话状态来源、资源路径、权限和现有测试；不要仅根据历史讨论假设版本或文件名。

运行本包检查脚本，列明：已有参考素材、缺失生产美术、缺失真实模型、SDK/Core 取得方式、可立即完成的代码。

产出 `asset-audit.md` 与最小集成方案。可以继续做不依赖缺失资产的工作，不要只停留在空泛计划。

### 阶段 B：制作基准与资产准备

先制备一张与定稿一致、透明背景、适合绑定的站姿生产立绘。默认优先保留母图主体的轻微三分之四角度，不强行改成标准动漫正脸。不要新增设计元素。

保持外观的图片处理、遮挡补画与 PSD 组装，可使用当前环境实际可用且授权允许的工具。需要外部图像生成或编辑能力时，列出真实需求，不声称不存在的工具调用成功。未通过外观确认前，不把新增补绘当作定稿。

按 `specs/layers.manifest.json` 制作透明部件和分层 PSD，补齐帽下、发后、袖下、袋后、鞋口等遮挡区。精细拆分数量可以合理调整，但必须记录变更。

### 阶段 C：真实 Cubism 模型

使用实际可用的 Cubism Editor 与合法工作流完成网格、变形器、参数、物理和动作。先完成 Idle、Hover、DragHold、PutDown 四种必需状态。

只有产出了真实可运行的模型，并在官方 SDK 中验证，才可称为 Live2D 完成。若环境不具备制作或导出能力，提供准确的建模交接清单及待导入资源目录，继续完成接入代码；不得伪造导出。

### 阶段 D：网页集成

优先采用官方 Cubism Web SDK/Framework 的匹配版本。先阅读正式示例与兼容说明，再固定版本。Core 从官方途径取得，不从不明 CDN 加载或假定 npm 包包含完整授权资源。

建立独立角色渲染层、交互控制层和业务桥接层。角色不进入白板素材集合，不参与导出。使用已有聊天开关和会话状态。

在真实资产尚未完成时，可以提供明确标注的静态占位或合法示例验证页；不要将其混入正式角色的完成状态。生产功能应受 feature flag 或资产就绪检查控制。

### 阶段 E：验收

按 `docs/05_acceptance.md` 逐项核验。对面部、鞋靴、工具袋提供实际渲染截图；展示悬停、拖动和聊天切换的真实运行记录；测试透明边缘命中、恢复位置、页面隐藏时暂停、异常回退和资源清理。

## 最终汇报必须包含

- 变更文件列表，以及哪些是实际完成、哪些是占位或规格。
- 真实资产目录与实际 SDK/Editor/导出版本。
- 运行方式、已执行测试与结果，未运行的测试明确标注。
- 缺失资产、权限或环境阻塞，下一步具体交付。
- 不修改无关白板功能、主导航或正式平台 Logo。

本包的 `specs/*.json` 是制作规格，不要当成 Cubism 的运行数据直接加载。
