# V2 拆层准备

> 当前正式制作入口已切换为 [front-v8/README.md](front-v8/README.md)。用户已批准 v8 完全正面母图及新配色；本页以下的旧三分之四视角、73 个 P0 部件和花饰/铃铛说明只保留为历史，不作为当前生产规格。

用户已确认 [v2 透明平面母图](master/forest-spirit-approved-v2.png) 并授权继续拆层准备，无需再次询问同一外观确认。[metadata.json](master/metadata.json) 记录实际像素尺寸、alpha、SHA-256 和批准范围。

**已完成的是母图归档与生产计划；尚未生成任何独立部件像素、PSD、补画或 Cubism 模型。** 不要将这里的 JSON 或母图复制重命名为这些成品。

图像通过内置 image_gen 工具制作；[实际生成提示词](master/generation.txt) 保留当时生成记录，其中“待审核候选”是生成时状态，最新用户批准状态以 [metadata.json](master/metadata.json) 为准。

[layers-v2.json](layers-v2.json) 列出 76 个计划部件（73 个 P0、3 个 P2），每个都标为 `missing_production_art`，包含独立 PNG 交付名称和像素/补画要求。所有 PNG 应使用母图实际画布和同一原点 `(0,0)`；可编辑拆层 PSD 与导入 PSD 使用 RGB、8 bit、sRGB。若后续需要高分辨率重绘，应单独记录来源与审校，不把放大当新增细节。

与旧清单的主要变化：

- 增加 `Eye_L_Cross`、`Eye_R_Cross`：只有眼内两笔 `+` 缝线，必须独立于棕色开眼及脸底。对应眼闭合时一起消隐，闭眼使用干净单弧，任何状态不得出现睫毛。原眉毛独立保留。
- 移除 `Hat_Tip`，将 `Hat_Crown` 改为 `Hat_Dome`；低圆顶、短波浪前后帽檐、陶红内衬、花叶果、带子和铃铛按 v2 拆开。旧尖帽物理参数不能自动视为已适配。
- 将原 `Skirt_OlivePanel` 改为 `Bodice_Olive`，增加三个橄榄绿短腰片与三个乳白裙瓣部件；披肩按短圆润波浪轮廓制作。每片背后补齐真实连续织纹，轻微摆动时不能露洞。

必须补画的隐藏区域：无五官脸底和额头；帽檐下发根、头发后的耳颊颈部；新圆帽底与内衬；短披肩下面的袖子、腋下与上身；花瓣裙相互覆盖部分和内裙；围巾、肩带、工具袋后面的衣服；袋内剪刀和纸卷隐藏端；裙后腿袜、靴口连接。

交付前提供：可编辑 `forest_spirit_separation.psd`、可导入 `forest_spirit_import.psd`、完整同画布 PNG 部件、图层顺序说明、补画区域说明和中性复合校对图。不要提交空白占位部件。先逐层复合检查，再检查白/浅绿/深绿底下发丝、蕾丝、帽缘、铃绳的透明边缘；抬手、轻侧头、衣片摆动姿态需验证遮挡补画。

这些美术交付真实存在后才能进入 Cubism 网格、变形器、闭眼与十字消隐、四组 P0 动作和官方运行时导出。本轮仍保持正式模型资源未就绪，前端不默认启用此角色。
