# 视频与音频回到创作白板

日期：2026-11-12；复核修订：2026-11-13。当前界面采用森织暖白、深绿与织芽角色，不复制参考产品的视觉样式。本阶段继续补齐生成媒体的审阅、整理、回到来源和下载链路。

## 交互行为

- 项目生成文件列表中的本项目视频和音频可明确放入无限白板；图片使用原有图片分支。
- 媒体节点保存稳定的`RunwayMedia`身份、类型、MIME、尺寸、时长和服装秀来源。私有文件播放地址由项目与媒体ID组成，不把短时签名地址写进画布快照。
- 播放需要用户主动点击，使用原媒体文件、原始音频、浏览器原生控制及HTTP Range流式读取。页面隐藏、所在编辑视图停用、白板将媒体移出可视区域、媒体自身隐藏或另一张媒体开始播放时暂停当前播放器。
- 媒体节点可作为设计背景的画布对象移动、缩放、隐藏、定位和刷新恢复。放置复用图片入口已验证的账号/项目草稿、幂等编号、未知回执核对和画布布局保存。
- 原文件下载先重新请求项目受控下载入口检查权限和文件存在，再由浏览器下载，不保存代理错误响应。
- 媒体不作为图像输入进入服装生成，也不作为普通图片引用发送给助手；当前模型输入链路没有可验证的视频/音频理解契约。助手的工作区对象摘要、引用菜单和定向恢复都会排除媒体。详情明示源文件及来源，保留将来增加获授权多模态模型的入口。
- 当前静态画布只导出位图。遇到媒体节点时明确停止本次PNG导出并提示下载原文件或隐藏媒体，避免成功回执中丢失作品。
- 归档服装秀的生成产物继续只读审阅与下载；白板媒体节点引用原件，不复制文件。项目/任务删除等上游清理保持现有约束。

## 权限与数据边界

命令服务在同一项目写事务内读取真实媒体、项目访问权和原对象存储head信息，确认原文件字节数及MIME后才写节点、绑定和摆放。拒绝输入/上传媒体、项目外身份、伪造地址、媒体格式或运行来源；绝不调用生成API、不创建视频副本、不起新的队列。

媒体节点在放置命令和语义工作流写入时与`RunwayMedia`记录交叉核对；普通工作流读取直接读取已保存节点，不会重新查询该媒体记录。生成文件列表将对应已有节点ID回填，重复摆放复用节点；多个独立摆放保持同一媒体身份。保存快照只增加摆放坐标及媒体身份，播放时仍从受控项目接口读取原始范围字节。

## 验证结果

- API真实HTTP/PostgreSQL/MinIO：媒体放回6项、范围播放/原文件下载1项、导出文件列表媒体定位与WEBP过滤1项，共8项媒体路径通过；另将图片放回、私有导出及工作流语义测试与媒体复测合并分批执行，共30项相关实际HTTP与数据库集成通过。测试使用仅属于本轮创建的隔离账号/项目并清理原媒体对象，没有启动正式Worker。
- Web单元：复核前留存的最近一次相关组为6文件36项通过，包含媒体身份/地址校验、卡片尺寸、对象目录和保存续办。
- 浏览器功能：留存的最终单worker运行日志为20项通过；此前将不同批次的图片放置、媒体与演示用例相加写成26项“不同功能场景”不准确，不再按批次相加为独立场景。覆盖范围以具体测试名称和运行日志为准。
- 2026-11-13复核：单worker重跑“白板隐藏媒体后停止播放，移动和刷新只更新摆放”，1项通过；标题区拖动会移动媒体节点并保存位置。
- 展示：本机合成的6秒服装展示示例和窄屏共2条演示录制；素材由仓库已有本地原型图片生成，不是模型输出或供应商作品质量证据。
- 静态与性能：shared build、API/Web类型检查、API/Web目标文件ESLint通过。Windows无头Chromium 145、DPR1、16逻辑线程、100个工作流素材及1个本地循环视频加1个本地循环WAV，单worker分三段30秒测量：暂停59.94 fps/长帧0%，视频59.97 fps/长帧0.056%，音频59.94 fps/长帧0.111%；均达到平均至少58 fps、长帧少于1%。事件到rAF P95为6.4/6.4/5.3ms。数据在`output/playwright/canvas-media/performance.json`。这是本机小文件的界面采样，不代表长时多路、高分辨率、真实供应商或实体设备性能。

截图与录制位于忽略目录`output/playwright/canvas-media/`：`garment-1440.png`、`garment-320.png`、`tour-1440.webm`及`tour-320.webm`。实际媒体使用点击后开始播放，截图证明卡片布局和作品呈现，不模拟自动播放。

## 尚未验证

没有把媒体接入服装生成参考、没有声称模型能够分析视频或音轨；这些需先确定并实际验证供应商多模态输入契约、计费与权限。没有实测手机硬件、4K素材、多段长片或并行媒体导出。动态视频导出也不属于静态PNG导出能力。首次回看Lovart网页时没有取得可核验正文，过程中关于该次读取成功的说法已撤回；本次功能以现有平台已验证的生成文件、私有媒体HTTP和白板保存契约为依据。
