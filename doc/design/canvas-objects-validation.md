# 画布对象目录验收

日期：2026-11-09。本阶段补齐浮动对象目录、查找、分组展开、选择与定位、层级调整、锁定和父级锁定保护。沿用森织的暖白深绿与毛绒织芽。

## 行为与边界

目录按前景优先列出对象，同名编号按对象身份保持稳定。查找保留匹配对象的祖先，八层分组仍可操作；目录投影排除坐标、尺寸和相机，拖动画布不要求整个列表重绘。循环或缺失父级的旧数据仍可检索。

开合目录不改变视野或重建聊天；选择不追加助手引用、不发送。锁定、层级修改随现有布局保存、撤销、重做和刷新保留；父级锁定保护后代。只读模式允许查找定位，拒绝修改。权威素材和版本更新保留锁定，手绘回执和新图投影不被布局锁阻断。

窄屏打开目录时隐藏并暂停织芽，关闭恢复。320×400 短屏保留至少一整行 44px 操作区域，临时隐藏重复视图切换。目录定位在窄屏关闭面板再展示对象。

## 2026-11-10 接续：对象显隐与导出稳定性

上述“尚未验收显隐”指11月9日阶段，本节记录接续后的实现与新证据。

对象行新增眼睛按钮，隐藏对象仍可搜索并恢复，刷新后保持原位置和锁定。显隐使用现有布局快照中的 `shape.meta.canvasHidden`，通过 tldraw 正式可见性接口参与渲染和命中，不新增后台状态。父级隐藏传给后代；父级恢复后，子级自己的隐藏选择仍保留。父级隐藏期间子级显隐按钮禁用，锁定不妨碍显隐，只读仍拒绝修改。

隐藏会清除当前选择及选中的祖先、退出隐藏的聚焦组；键盘全选也排除隐藏对象，随后删除不会误删直接隐藏的对象。选中的可见容器整体删除仍保留原有容器语义。容器引用跳过隐藏子树，已明确添加的聊天引用保持；外部结果定位优先可见副本，全部隐藏时打开详情。素材版本更新、手绘回执及手绘转图片均保留显隐与锁定。

导出、查看全图和目录定位采用可见内容范围。普通分组不绘制自身，排除其包含隐藏子级的旧几何范围；画框自身仍属于作品。全部内容隐藏时给出明确提示，不下载空白 PNG。

实际 PNG 检查发现，材质外壳在导出时新建，入场淡入曾导致导出颜色随时间变淡。已使导出使用稳定姿态和完整材质，悬挂装饰也不播放入场动画；选中图片的“局部更改”操作不进入导出。红绿蓝受控图片验证了连续导出的颜色、选择前后文件一致、分组子级隐藏后的像素与尺寸、整组隐藏和全部隐藏。实际下载文件位于 `output/playwright/canvas-visibility/`，包括 `all-visible.png`、`all-visible-again.png`、`selected-image.png`、`one-visible-child.png`、`hidden-group.png`。

便签在导出时使用静态文本，避免浏览器把原生文本输入框边框带入PNG；色卡去掉添加、删除、改色控件。导出副本不触发布局尺寸修复或便签自动增高。作品中的图片、便签内容、色值、名称及角色标签保留。混合画布补充检查确认缩小六次前后的PNG文件逐字节一致，导出前后保存文档相同；导出画面观察记录中没有添加颜色、局部更改、改色输入或文本输入控件。产物为 `mixed-board.png`、`mixed-board-zoomed-out.png` 与 `export-audit.json`，已检查图片中的文字与色卡。
