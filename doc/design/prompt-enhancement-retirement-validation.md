# 提示词增强与旧设计流程退役

日期：2026-11-15。用户确认采用 WorkBuddy 式输入框主动增强；保留画布和助手直接生图，退役旧需求分析、方案生成独立流程与服装评估，不删除已有图片和历史。

## 最终行为

- 输入框麦克风旁增加“增强提示词”星芒图标，仅点击时提交当前文字与明确引用。增强使用独立项目级接口，不发送聊天、不创建创作节点、不提交生图任务，也不读取全项目作为默认输入。
- 结果回填同一草稿，保留引用，提供一次撤销。期间文字或引用变化时保留当前内容，增强结果需明确采用；此时撤销恢复采用前的最新输入。错误、取消与账号／项目／会话切换不接受迟到结果。
- 普通发送、画布生成和助手明确生成继续使用已确认文字、引用和参数。新的生成入口不调用需求分析、提示词增强或旧的分析后续生成分支。
- `generate_design` 只保留为图片生成的内部兼容标识，公开名称为“图片生成”。模型清单与新回复协议不开放 `analyze_brief`／`evaluate_design`。新建旧类型目标、新规划、旧参数配置和新执行均被拒绝；旧类型和执行器保留读取及已提交命令恢复能力。
- 全部功能面板移除需求分析和方案评估入口；旧节点仍可查看参数、报告和历史，不能启动新的旧流程。文本起草、图像修改、裁剪与变换、真实图片和已有版本关系继续保留。
