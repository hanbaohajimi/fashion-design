# 工作室子功能重设计实施记录

日期：2026-10-25。范围为工作室导航与全部 11 个子功能，沿用暖白、深绿，并采用用户补充允许的区域配色。工作台助手、流程画布及后端协议不属于此次实现范围。

## 实现与覆盖

共享颜色仍由 `apps/web/src/styles/design-system.css` 管理：作品区 `#ececea`、编辑区 `#e8eee7`、资料区 `#eee8dc`。这些颜色区分区域用途，不代替失败、审批等状态文字。导航使用仅作用于工作室的浅色 184px 变体，11 个入口按创作、交付、资料排列，项目跳转集中在顶部。

| 子功能 | 当前主内容 | 按需操作 |
| --- | --- | --- |
| 开始任务 | 已选参考与本次要求 | 参考选择、品牌规则；显式生成 |
| 款式档案 | 完整主图、视图缩略图、准确修订 | 编辑款式资料、比较候选、保存修订 |
| 色料实验 | 母图与同批结果并列、失败项可重试 | 下一轮配置；保存计划和执行仍分离 |
| 印花工作台 | 完整平铺预览与常用尺度/旋转 | 图案资料、生产参数、高级调整 |
| 商品展示 | 当前图与有序缩略图 | 逐图核对、展示资料、保存及导出 |
| 系列规划 | 系列位置与当前选中项 | 选中位置编辑，收起后保留同一草稿 |
| 技术包 | 当前章节内容与章节目录 | 章节内编辑、独立复核章节、历史 |
| 样衣反馈 | 样衣照片、问题锚点与问题导航 | 当前问题编辑、轮次与照片资料 |
| 团队评审 | 关联修订作品与意见 | 切换评审对象；成员管理保留独立入口 |
| 趋势简报 | 已选来源与简报内容 | 来源选择、摘要方向和品牌关联 |
| 品牌资料 | 摘要、色彩、认可案例 | 编辑品牌资料、进入共享品牌库 |

`StudioEditSection` 仅管理展示状态，字段保持挂载，继续使用原表单与保存请求。手机主动编辑进入原生全屏 dialog，关闭/返回恢复焦点并保留草稿；新建对象的初始输入直接显示。原生校验和技术包自定义校验都会定位字段，必要时退出挡住字段的编辑层。只读成员可展开资料，编辑权限不扩大。

## 前后任务路径

计数从对应功能与已有对象已加载开始，一次点击、选择、拖动或完整字段编辑计一次；不含滚动、逐字输入与网络等待。根据真实组件交互和回归断言核对，属于任务路径分析，不是设计师耗时实验。

| 同一任务 | 改造前 | 改造后 | 变化 |
| --- | --- | --- | --- |
| 查看同批色料结果 | 0 次；手机先越过整块配置 | 0 次；母图直接进入结果区 | 减少配置干扰，母图同屏可比 |
| 进入款式候选两图比较 | 最少 4 次 | 最少 4 次 | 未声称减少步骤；仍可独立选择 2–4 张候选 |
| 调整已有印花尺度并保存 | 2 次 | 2 次 | 高频控制直接可用，资料收起 |
| 从基本资料修改 BOM 用量并保存 | 3 次 | 3 次 | 完整发布清单移到复核章节 |
| 已有样衣新增问题、定位、描述并保存 | 4 次 | 4 次 | 图片优先，轮次资料按需展开 |
| 编辑已有对象名称 | 字段直接出现 | 打开资料后编辑 | 有意增加一次资料展开，默认阅读更清晰；收起不会丢稿 |

本轮没有宣称所有动作数下降。保存、复核、发布、导出仍是不同动作，人工确认与准确修订绑定保持不变。
