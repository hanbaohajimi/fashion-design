# Design System: Atelier 设计工作室

## Overview

**Creative North Star: "中性浅色专业工作台"**

本记录描述 2026-10-25 仓库中现行生产 UI，不宣告本轮全平台重设计完成。浅灰承托作品，白色承托操作与资料；靛蓝标示动作、选中和焦点，品牌茜草与材料色板承担各自有限语义。中文工作界面使用无衬线字体，层级主要靠字号、400/600 字重、间距和结构建立。

用户已授权全面重设计，但先比较三个可交互方向，再选定推广。`src/prototypes/impeccable/` 与 `src/app/prototypes/impeccable/` 属于独立局部 CSS 的开发原型；其配色、字体、结构与模拟状态不属于本记录的生产设计规范，不能据此替换运行时主题。新的创意方向尚未确认；这里的 North Star 沿用当前实现中的描述。

**Key Characteristics:**

- 中性浅色表面与独立图像台。
- 动作、选择、焦点、状态和品牌分别命名。
- 作品保持原比例；资料通过分组与章节展开。
- 桌面侧栏与窄屏选择器适配不同可用空间。

证据优先级：当前源码 → 当前基线审查 → 历史实施文档。运行时唯一主题为 `src/styles/design-system.css`，由 `src/app/globals.css` 导入。上下文来源为 `PRODUCT.md`、`../../doc/全系统视觉与交互重构-2026-10-24.md`；`design-tokens.css` 与旧深色 `design-system-v2.md` 已归档。审查依据 `../../output/impeccable-redesign/baseline-a/report.md`（含 73 张截图的覆盖说明）；本次文档提取没有重新执行浏览器审查，亦不声称逐张复核这些图片。

前置 YAML 是现行复用值的机器可读快照；运行时仍以 CSS 为准。`colors` 的名称对应 `--color-<name>`，`swatch-*` 与 `image-stage-background` 对应同名 CSS 变量；`rounded` 对应 `--radius-*`，`spacing` 对应 `--space-*`。不把兼容别名再复制成第二套原色。仅记录实际使用的文字角色，未将所有声明过的超大字号固化为标题规范。

## Colors

浅灰与白色构成主要工作表面，饱和靛蓝承担明确操作，材料色保留服装素材的分类特征。

### Primary

- **动作靛蓝**（`action` 系列）：保存、提交等主操作；hover、active 独立。
- **浅蓝选择**（`selection-*`）：已选对象、页签和导航；与轮廓、侧线或下划线共同表达选中。
- **焦点蓝**（`focus-ring`）：键盘定位，与对象选中语义分开。

### Secondary

- **品牌茜草**（`brand` 系列）：品牌入口和少量标识；不是通用导航色。
- **材料色板**（`swatch-*`）：羊毛、亚麻、茜草、靛蓝、姜黄、鼠尾草、紫草及其 wash，用于素材角色和色卡。`workflow-edge-*` 是连线专用深色。

### Neutral

- `canvas` / `paper` / `surface` / `overlay` 区分页面、面板和次级表面；`studio-canvas` 与 `image-stage-background` 承托作品。
- `ink`、`ink-secondary`、`ink-tertiary` 区分主文字、说明与元数据。控件边界与一般分割线分别使用 `control-border`、`border`、`divider`。
- `disabled-*` 使用独立禁用值；`scrim*` 用于遮罩。`inverse` 系列是反色材料，实际共享 Tooltip 使用 `ink` 与 `paper`，不要将声明值误作该组件的计算值。
- `status-success`、`status-warning`、`status-error`、`status-info`、`status-running` 及其 bg 对应状态，图形与文本必须同行。

**The Semantic Separation Rule.** 动作、选择、焦点、品牌和状态使用各自语义变量；颜色相同也不合并用途。

Sidecar 的八级 tonalRamp 仅供色板预览，均为合成 OKLCH 插值，不是生产新增 token，也不代表已完成对比度验证。

## Typography

**Body Font:** YAML `body.fontFamily` 保留完整 Inter / 中文无衬线 / 系统回退栈。**Brand Font:** YAML `brand.fontFamily` 保留 Palatino / 宋体回退栈；AppHeader 的 A 标识使用斜体，品牌文字本身为无衬线。**Label/Mono Font:** 正常标签仍用无衬线；统计数字局部使用 CSS `--font-mono`。

页面标题取项目库 `.dashboardTitle`，模块标题取 `WorkspaceHeader` 与 Studio section，区块标题取 Studio h3。正文和共享控件共用 body，状态标签使用 label。角色值见 YAML；正文通常 400、强调 600，当前 `--font-medium` 实际也是 400，不按名称推断为 500。项目名侧栏为 16px，窄屏对象标题为 14px，是紧凑上下文而非另立页面标题。

说明段在 WorkspaceHeader 最宽 64ch；EmptyState 说明最宽 44ch。手机文字输入以及 any-pointer: coarse 下文字输入强制至少 16px。没有确立新的 display 字体；不得将开发原型的字体带入生产。

## Layout

- AppHeader 最小高度 56px；桌面横排品牌、三项全局导航与账号。全局内容上限 token 为 1600px，页边距默认 32px，宽度至少 1600px 时 48px，最多 767px 时 16px。组件仍可有局部布局，不把 token 误当所有页面固定宽度。
- StudioWorkspace 桌面为 216px 侧栏加可伸缩内容列；侧栏 sticky、独立纵向滚动，主区左右 24px。宽度最多 1023px 时隐藏侧栏，显示项目上下文及按分组排列的原生“当前功能”下拉框。
- Studio 在最多 600px 时表单、比较、评审和图片资料进一步变成单列。章节编辑区仅在至少 1024px 宽且至少 640px 高时采用受视口约束的布局；低高度允许自然滚动。
- AppHeader 最多 900px 时收紧间距、隐藏品牌副标题；最多 600px 时全局导航另起一行，账户名称截断。该局部边距覆盖与全局 safe-area padding 的关系应另做真实设备复核。
- 间距以 4px 基础尺度与 8px 节奏组织；表单字段通常间隔 16px、区块通常 24px，局部组件保留自己的密度。
- 默认、紧凑、主操作控件最小高度分别 36 / 32 / 40px；粗指针下统一为 44px。图片按比例展示，`ImagePreview` 默认 contain，cover 仅为显式可选项；不能推断全站所有封面都 contain。

## Elevation & Depth

**The Domain Depth Rule.** 普通工作面靠表面与细线组织；材料投影属于作品与素材，弹出层使用专用阴影。

阴影原值保存在 sidecar 的 `extensions.shadows`，直接提取 CSS：none、hairline、ui、material-1/2/3、popup、modal。UI 层低投影；画布材料为多层柔和投影；菜单与 Tooltip 使用 popup，原生 Dialog 使用 modal。源码旧注释曾称暖墨 31,29,26，实际阴影为 24,24,24，本文遵从实际值。没有把历史注释当成另一套阴影定义。

## Shapes

控件、菜单、标签、卡片和弹窗采用对应圆角 token。共享控件为 md，Badge 为 sm，规划卡与菜单面板为 lg，Dialog 为 xl；full 用于滚动条等胶囊端部。按钮默认细边框，主操作边框与底色同色；规划卡默认平面边框，选中时出现外轮廓。避免把所有资料都套进卡片，现有记录也使用单条上边线。

## Components

### Buttons

`Button` 的 variant 为 primary / secondary / ghost / danger，默认 secondary；size 为 default / small。共同 padding 和颜色见 YAML；small 使用 4px 12px，文字仍为 14px。Hover 改变表面/边框，primary 有独立 active 色；按下没有位移。共享焦点环为 2px，偏移 3px。禁用使用独立底色、文字、边框；loading 保留原按钮名，禁用点击、设置 aria-busy，300ms 后显示不改变宽度的绝对定位等待标记。IconButton 必须提供 label。

### Inputs / Fields

Input、Select、Textarea 共用白底、控制边框、md 圆角与 body 字体；textarea 可纵向缩放并使用 1.65 行高。aria-invalid 切换错误边框；Field 的错误优先于 hint 并使用 role=alert。disabled 输入仍显示可读文字。错误提示和重试入口应与实际请求状态一致。

### Chips / Status

Badge 有 neutral / success / warning / error / info / running；状态 Badge 同时包含轮廓 SVG 和文字。Notice 复用状态配色，error 使用 role=alert，其余 role=status。它们不是可点击的筛选按钮。SegmentedControl 使用 aria-pressed 和选中内描边，左右键切换并移动焦点。

### Cards / Containers

规划卡为白色 lg 圆角、16px padding、12px 内间距的网格按钮，选中时 2px 焦点色轮廓。记录行使用上分割线与 20px 纵向 padding。章节表单、作品与操作条各自保留占位；共享 ActionBar 只负责状态及操作布局，不自行推断保存或生成行为。

### Navigation

AppHeader 提供项目库、面料库、趋势档案；当前项 aria-current=page，蓝色字与底部 2px 线。带 projectId 时保留返回上下文参数。StudioNavigation 通过常用入口和功能分组展开；窄屏使用 Select。Tabs 是手动激活：方向键/Home/End 只移动焦点，不自动启动昂贵面板；TabPanel 通过 hidden 控制可见性。

### Dialog / Menu / Tooltip

Dialog 使用原生 showModal，选择首个有效控件作为初始焦点、约束 Tab、Escape 关闭并恢复触发焦点；最大尺寸扣除视口边距与安全区。Menu 用 details，外部点击/选择关闭，Escape 返回 summary，方向键遍历。Tooltip 可通过键盘立即显示，鼠标等待 180ms、关闭延迟 120ms；触摸不触发 hover 提示，Escape 关闭；进入 dialog 时挂入该原生模态内。

### StudioWorkspace / Loading / Motion

StudioWorkspace 区分首次加载 Skeleton、Notice 错误、不可打开 EmptyState、数据内容、刷新中及只读。离开脏草稿或刷新前走现有 guard；切换模块更新 tab，离开款式移除 assetId。表单 invalid 会展开祖先 details。不能将这些状态记录当作本轮已新增的行为。

CSS 共享过渡以 fast=140ms 的颜色、背景与边框变化为主；normal=180ms、result=280ms，instant=90ms。UI 组件未显式指定的 easing 由 CSS 默认 ease 决定，不虚报为 standard。JS motionDuration 从 CSS 读取并响应 reduced-motion。事件驱动装饰时间轴、曲线与兼容等待周期见 sidecar，不作为每个表面的强制动画。busyMark 的 1.2s 呼吸及 revisionSaved 的透明度过渡有独立 reduced-motion 分支；根变量在 reduce 时归零核心 duration 与 AI 周期，不能据此声称所有 motion-* token 都会自动归零。

## Do's and Don'ts

### Do:

- Do 从 `src/styles/design-system.css` 读取现行语义变量；兼容别名只用于延续旧调用。
- Do 在选中、运行、失败和只读状态保留文字、标记或图形；复用已有重试和未保存保护。
- Do 保留键盘焦点、原生弹窗焦点返回、触控尺寸与减弱动态分支。
- Do 在原型选定并实际推广后重新提取生产 tokens，而后更新本文与 sidecar。

### Don't:

- Don't 把尚未选定的三套原型或已废弃的 `design-system-v2.md` 当作生产主题。
- Don't 用品牌茜草替代常规主操作色，或用错误色覆盖作品图片。
- Don't 将微标签、眉题和字符图标等现存问题复制为新的系统规范。
- Don't 把 fixture 截图、模拟生成或导出状态当作真实模型、队列和用户验证证据。

**未规范化、未修复：** Studio 现有 eyebrow / micro-label、返回箭头和关闭/上传字符图标不作为可继承的设计规则。基线指出跨模块素材序号、比较图库重复、手机长表单优先级和交付复核概览不足；这些属于待比较的重设计问题，而非已确认的系统模式。源码中的局部 13px 保存提示、旧注释差异与全局未统一的媒体断点亦保持如实记录。此文档变更不修改生产 UI，不证明完整可访问性或真实用户验证已经完成。
