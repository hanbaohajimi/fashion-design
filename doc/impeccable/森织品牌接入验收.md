# 森织品牌接入验收

日期：2026-10-25。此次交付统一用户可见品牌为“森织”，接入透明 Logo、浏览器图标与设备触摸图标，并重做登录页。内部标识、历史原型与业务 API 保持原样。

## 实现与素材

- 共享 `BrandLockup`：浅色/彩色图形、指定尺寸、可选品牌文字。图文并列时图形的 alt 为空，单独图形使用“森织”；图片预留正方形尺寸，保持比例，首屏立即加载。
- 桌面导航使用 44px 浅色图形与中文品牌；窄屏导航沿用原有布局。
- 登录页在 ≥900px 使用暖白品牌区与深绿表单区，比例 55:45；窄屏保留 64px 标识与表单。登录主按钮 48px，重发与更换邮箱触控区至少 44px；长邮箱可换行，失败提示自然撑开卡片。
- 登录确认、全局/局部错误页、公开分享、页面 metadata 同步更名。通过 Next.js 文件约定接入多尺寸 ICO、32px icon 和 192px apple-icon。
- 素材来源及限制见 [SOURCE.md](../../apps/web/public/branding/SOURCE.md)。未重新生成或描摹图形。真实背景上未发现阻碍使用的明显白边；16px 图标只能呈现总体轮廓，人物、圆弧与星芒等细节仍较密，后续可替换为专门精简的母版。

视觉验收使用仓库固定 Linux Chromium 环境，设置 `ATELIER_VISUAL_REVIEW=1`，先生成候选图，再人工复核并复制受影响基线。视觉服务使用 `NEXT_DIST_DIR=.next/forest-visual`，构建使用 `.next/forest-build`，避免占用正在运行的开发缓存。检查后恢复开发类型引用至 `.next/dev/types`。

新增测试覆盖 1440、1024、390、320px；检查无横向溢出、Logo 加载及比例、文字对比度、控件字号和按钮高度。交互覆盖发送中、网络错误、HTTP 错误、重试、重发、更换邮箱与键盘操作，以及 Logo 加载失败时仍可登录。检查了品牌 metadata、图标响应、导航返回、无效登录链接和公开分享入口。

人工核对了登录页各尺寸及成功/失败状态、项目库、登录确认页、款式档案、品牌资料与流程画布。工作内容区沿用原有设计。导出页不显示品牌，本轮保留其原基线，避免纳入无关的细微截图差异。

浏览器测试使用模拟 API，不代表真实邮件投递、队列、数据库或模型链路验收。构建与浏览器日志仍有既有 Sentry 导入弃用、tldraw 缺少部分中文翻译和被拦截字体请求提示，均未导致本轮检查失败。
