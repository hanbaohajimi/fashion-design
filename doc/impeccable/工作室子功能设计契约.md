# 工作室子功能：作品为主，按需编辑

用户确认范围：工作室全部 11 项；保留品牌色彩，重做导航；不覆盖助手、流程画布和外围页面。2026-10-25 补充授权：适当引入新颜色及区域块。

## 方向与区域

- Operate 模式。作品、文档或当前集合是页面中心；已有对象默认可阅读，资料按需编辑，新对象显示必要输入。
- 浅色 184px 工作室导航按创作、交付、资料显示全部入口。低于 1200px 使用可见功能选择器，项目跳转集中到顶部。
- 主作品台使用中性 `--studio-artwork-surface`，当前操作区使用灰绿 `--studio-work-surface`，关联资料及章节使用暖沙 `--studio-reference-surface`。区域色只表达用途，不作为运行、失败或审批状态。
- 三种结构：作品与工具并排；章节目录与内容；作品集合与选中项。桌面图片类作品区域至少占内容宽度 60%。无内容时不编造作品。
- 同一任务区域仅一个强调操作；生成显式执行，保存不自动生成，发布与导出保留现有复核限制。

## 实现契约

- 业务请求、修订 payload、权限、离开保护、深链保持原契约。前端只增加可见性和选择状态。
- 编辑字段保持挂载，关闭编辑保留草稿。手机主动打开资料编辑时进入原生全屏 dialog；Escape/返回恢复触发按钮焦点。新建默认输入不自动遮住来源。
- 主体图片保持原比例；样衣定位仍以真实图片边界计算。关联款式来自绑定的准确修订。
- 技术包完整发布检查仅放在复核章节；摘要显示缺失数量，错误定位并展开输入。
- 关闭系列位置编辑不卸载草稿；再选同一位置继续，切换位置仍经过离开保护。
- 所有颜色从唯一主题入口读取，不向其他页面传播工作室的导航及区域样式。

## 验收

11 项页面采集 1440×900、1366×768、390×844、375×812、720×450；最后一个尺寸是 200% 等效可用空间。模拟项目截图明确标记，服装素材沿用现有带来源记录的本地图片。

验证：草稿保留、焦点返回、显式保存与执行、精确修订、失败重试、只读、长文本、空状态、缺图、横向溢出。运行 Web 静态检查、单元、构建、业务 E2E 和固定 Docker Chromium 视觉回归。独立审查通过后才推广截图基线。

本轮为既定方向的代码实现，没有新 comp 或新的 QUALITY BAR 抽签卡。旧方向的截图只作为前后比较，不能替代此次独立复核。测试数据不代表真实设计师使用反馈，也不证明数据库、队列或真实导出内容正确。
