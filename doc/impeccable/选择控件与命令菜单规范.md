# 选择控件与命令菜单规范

2026-10-27。适用于自有生产页面；历史原型与 tldraw 内建菜单不纳入本轮迁移。

## 判断顺序

先判断语义，再判断数量与空间。写入字段、筛选条件或当前对象是数据选择，即使立即生效也不因此变成命令；删除、导出、跳转是命令或导航。边框是项目视觉约定，等待表单提交不是 Select 的必要条件。

“Select 用于选择，而 Dropdown 是命令集合”可直接核实于 [Ant Design 官方文档](https://ant.design/components/dropdown-cn/)。以下数量和限高是本项目约定，不归因为 Arco 官方硬性要求。

| 场景 | 默认呈现 |
| --- | --- |
| 2–4 个互斥值 | RadioGroup；长标签换行 |
| 立即生效的布尔设置 | Switch |
| 5–10 个值 | ChoiceSelect |
| 超过 10 个值 | ChoiceSelect 顶部搜索 |
| 1–4 个命令 | 可见按钮或链接 |
| 更多命令 | Menu；超过 10 项提供搜索，导航保留分组 |
| 图片选择 | AssetPicker，暂存后确认，预览不改变选择 |
| 熟悉的精确数值 | 直接输入，例如缩放百分比 |

占位提示不计数；“全部”“本次不关联”计数。过滤结果减少不切换控件，不自动选中第一项。当前值消失时显示不可用并保留值，要求用户自行重选。

## 组件与表单

共享 `ChoiceSelect` 使用 options/value/onValueChange，选项支持 label、description、group、disabled。支持 required、disabled、错误说明、键盘与焦点返回；选择、搜索和关闭不额外提交所属表单。`Select` 桥接原有 option/optgroup/onChange 调用，内部使用相同界面；隐藏原生 select 仅用于 FormData 和约束校验，不再显示原生弹层。

`RadioGroup` 负责互斥值和方向键；`Switch` 负责单一布尔设置，不能代替两个独立命令。`Menu` 不写入草稿字段，只承载按钮、链接和辅助说明。任务类型属于草稿值，功能导航属于页面入口，二者分开。

款式、品牌、样衣与技术包的 ObjectSwitcher 是文档流中的对象展开列表；保留现有缩略图、修订信息和离开保护，共用顶部搜索、264px 以内的搜索与结果区，以及无匹配提示。搜索即使只有一条记录也保留，不把对象列表误归为命令菜单。

图片字段采用已有 AssetPicker；款式视图、技术包、样衣照片、批注、实验母图、印花来源、服装秀设计图片和服装配对沿用稳定图片/媒体 ID。服装秀的款式修订仍按明确修订身份选择，不把不同来源转换成同一种 ID。

## 弹层与手机

锚定面板整体最高 264px，搜索固定在顶部，列表独立滚动。桌面优先向下，空间不足时向上。手机沿用 <768px：打开时使用可见视口判断触发器中心；位于上半区且下方空间足够时向下，其余使用底部 Sheet。一次打开期间不因键盘或搜索结果切换形态，不横向弹出。

Sheet 按可见视口和安全区布局，不受 264px 限制。复用原生 Dialog、Sheet、既有动效与减弱动态；Dialog 内的弹层留在所属模态层。Escape/取消恢复触发焦点；Tab、外部点击和新模态出现时不抢走下一个操作的焦点。中文输入法确认不误选或提交。

## 登记例外

| 位置 | 例外及理由 | 替代方案 |
| --- | --- | --- |
| 项目卡片 | 四个次级命令保留 Menu；重复卡片常驻四按钮会挤压作品与项目名 | 主入口“继续创作”常驻，次级动作由菜单展开 |
| 窄屏全局导航、工作室功能导航 | 少项也可收纳；窄屏空间有限，导航需要稳定入口 | 桌面使用常驻目录，功能导航保留分组、搜索和当前项 |
| 完整流程画布“资料与更多” | 专家工具栏收纳次级导航、历史与导出 | 日常工作台与全局目录保留直接入口 |
| 技术包 BOM/POM | 单元格短选项使用 compact ChoiceSelect，保持表格宽度和行高 | 普通表单使用平铺单选，手机表格条目沿用同一控件 |
| 系列、品牌、对象、修订、会话及执行历史 | 少项也固定保留搜索式选择器，避免数量增长造成界面切换 | 静态枚举继续依数量平铺或 Select；搜索只覆盖已加载记录 |

不得把这些例外扩大到一般表单或单一退出、刷新、暂停命令。新增例外必须注明具体位置、空间约束与直接入口。

## 验证记录

组件测试覆盖 2/4/5/10/11 项、真实空值与占位、表单值及必填、禁用、键盘、中文输入、取消、动态记录、单次回调与命令搜索。浏览器测试位于 `tests/e2e/choice-governance.spec.ts`，验证桌面、手机上下方弹层、缩小视口、导航离开保护和图片确认；相关业务测试继续验证稳定媒体 ID、历史切换与权限。

本轮测试日志与截图保存在忽略的 `output/choice-governance/`。浏览器使用隔离 API fixture；视口缩小模拟键盘空间，不代表真实手机键盘、数据库、模型或队列已验证。
