# 统一浅色导航

2026-10-26，用户明确选择第二张参考图的暖白导航与彩色 Logo，并授权推广到整个系统。以现有工作室浅色体系为基础，保持项目、作品、修订、权限和草稿保护。

## 方向

Operate 模式。项目库、设计工作台、工作室、面料与趋势使用同一个 ArchiveNavigation，不再按路由切换深浅主题。暖白导航、深绿文字、浅灰绿选中态；主操作继续深绿。图片和画布保持中性工作底色，登录区域采用同一浅色体系。

## 首屏与交互契约

- ≥1200px：统一 184px 导航，Logo 在顶部，账户固定在底部。项目中的全局入口顺序一致：项目库、设计工作台、款式与交付、面料库、趋势档案。进入项目后才提供项目内入口。
- <1200px：所有页面统一为 64px 导航栏；彩色 Logo、带下拉标记的当前工作区菜单、账户按固定顺序排列。菜单保留项目名、当前入口、键盘访问与 Escape 焦点恢复。
- 工作室 11 项功能按原分组直接提供，局部目录可独立滚动。进入页面或切换功能时，当前选中项滚动到可见范围；不会挤走账户入口。
- 当前项目、已有 URL 参数及离开保护保持。导航仅切换页面，不生成、发布或丢弃草稿；放弃草稿仍需原确认。
- 主要证据是项目首页→工作台→技术包→资料库的实际渲染与交互。新旧导航颜色差异消除，不用过场动画遮掩结构变化。
