# 工作室层级推广实施记录

日期：2026-10-26。范围：项目内 `/studio` 的 11 个子功能。

用户在商品展示包样板完成后明确要求“推广”，本轮将对象身份、主要工作面、辅助资料的层级扩展至其余 10 页。依据为 [工作室层级推广契约](../../apps/web/.impeccable/surfaces/studio-workspace.md)、[PRODUCT.md](../../apps/web/PRODUCT.md) 和 [DESIGN.md](../../apps/web/DESIGN.md)。商品展示包原始局部契约保留为阶段记录，并追加后续授权覆盖说明。

## 落地范围

推广页面使用 `StudioPageHeader` 集中对象名称、类型/说明、状态和次级操作；商品展示包保留同层级的独立页头。主标题为 28px / 600 / 1.35，≤767px 为 24px；主要区域和常驻资料标题为 18px，资料摘要与素材选择说明为 14px。系列空态引导另有局部 22px 标题。以上作为工作室局部角色写入 DESIGN.md 前置 token，不替换全局标题或正文尺度。

| 子功能 | 当前工作结构与响应式 |
| --- | --- |
| 开始任务 | 来源工作面 + 320px 输入列；≤1099px 改 280px，≤767px 单列，来源在输入之前。 |
| 款式档案 | 伸缩作品/素材区 + 296px 常驻资料；≤1099px 单列，≤767px 字段单列。主图 contain，`clamp(300px, 48dvh, 520px)`。 |
| 色料实验 | 母图/结果区 + 340px 配置；≤1099px 单列且结果在前，手机母图高 280px。 |

共享目录仍在 1200px 切换，768–1199px 的“当前功能”选择器已覆盖所有子页。工作室通过 `currentIsParent` 将“款式与交付”父级入口改为透明底、500 字重，`data-studio-hierarchy` 将子功能左缩进 8px，实际选中子页保留浅绿底、600 字重；其他页面的共享导航样式不变。常驻资料参与正常文档流，不打开手机编辑模态。`StudioEditSection` 的非 persistent 兼容分支仍保留按需展开和原生 dialog 行为，不能据此推断当前所有页都使用模态。

`AssetPicker` 将选择、已选顺序、素材名称与独立原图预览分开；查看大图不改变选择。`SaveBar` 区分新资料尚未保存、有未保存修改、保存中、已保存和只读，长表单底部操作保持可达。保存修订、提交生成、人工核对和发布保留显式操作及原权限；没有新增自动保存、图片排序、封面或导出能力，没有 API、共享契约或数据库变更。

本轮同步只调整 DESIGN.md 中对应的工作室 token、布局、组件说明，以及 design.json 的局部元数据和相关组件片段。既有无关改动、全局色彩/字体与其他页面规范保持原状；不是整个应用的统一双栏规范。
