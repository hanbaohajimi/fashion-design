# 商品展示包工作区实施记录

日期：2026-10-26。范围：商品展示包 `Operate` 页面及仅在该页启用的导航层级。初审确认主体设计成立；唯一 P1 断点问题修复后，定向终审结论为 `ship`。该结论仅覆盖本次页面与修复复核，不代表整个平台验收通过。

## 继承与局部调整

继承 [PRODUCT.md](../../apps/web/PRODUCT.md)、[DESIGN.md](../../apps/web/DESIGN.md) 与 [design.json](../../apps/web/.impeccable/design.json) 中现行「织物档案」世界：暖白纸面、深绿文字与动作、浅灰绿选择、中文无衬线、共享字段和按钮。服装图片保持原比例与完整轮廓，状态继续由文字、选择标记及明确操作表达。本次没有修改上述全局文档、sidecar 或全局 token，也不将本页布局推广到其他子页；工作区原有无关改动保留。

实现入口为 `apps/web/src/modules/studio/PresentationSets.tsx`，素材浏览与大图拆为 `PresentationGallery.tsx`，局部样式为 `presentation-sets.module.css`。与原来的纵向长表单相比，先展示当前对象和素材工作面，关联款式、名称、渠道与说明留在资料列；“整理素材”和“逐图核对”切换视图但共享同一份草稿。

| 方面 | 本页落地 | 适用边界 |
| --- | --- | --- |
| 层级 | 对象标题、草稿/已核对状态与已保存修订居前；主工作面用纸面，辅助资料不再逐组套描边卡片 | 保留输入、选中、键盘焦点及操作栏分隔线；不是全局禁用边框或阴影 |
| 桌面布局 | 伸缩素材列 + 296px 资料列，列距 28px；≤1399px 改为 280px / 24px | 本页 CSS 数值，不新增全局 token |
| 窄屏布局 | ≤1099px 主区单列、资料区两列；≤767px 资料与复核字段单列，手机素材仍为两列缩略图 | 正常文档流，无内部工作面纵向滚动；底部操作栏 sticky 并计入安全区 |
| 图片 | 素材舞台 272px 高，手机 210px；复核图使用 contain，大图复用 Dialog | 查看大图与选入展示包是两个独立动作，不因预览改变选择 |
| 导航 | 父级“款式与交付”弱化，当前“商品展示”保留选择强调；项目内功能略缩进 | `currentIsParent`、`data-presentation-hierarchy`、`data-presentation-page` 仅随 `tab === "presentation"` 启用 |

导航继续使用共享 `AppHeader`、`ArchiveNavigation` 和 `StudioNavigation`，保留项目上下文、URL、11 项入口和离开保护。初审发现 1024–1199px 共享断点不一致造成当前功能选择器缺失；本页以 768–1199px 的属性限定规则恢复它，并覆盖 1199/1200px 边界。其他页面的同类共享断点问题不在本轮修复范围内。

## 业务与交互边界

- 最多选入 12 张，按加入顺序保存；移除后重新加入排在末尾。没有新增拖拽排序、封面或自动保存能力。
- 保存修订继续写入 `DRAFT`；“核对并完成展示包”通过原 schema 检查后写入 `READY`。更改逐图视图或说明会重置该图人工核对标记，修改草稿会回到 `DRAFT`。
- 无款式时可临时整理素材，资料列和操作栏明确说明保存前置条件；前往款式档案仍经过未保存保护。新建、切换对象、冲突重载保留原保护机制。
- “生成展示候选”进入既有实验设置，确认后才生成。按钮不直接调用付费生成，也不伪装生成完成。
- 只读时资料与图片仍可浏览，选择、编辑与保存禁用。失败保留草稿与重试身份；原生必填校验可展开隐藏的逐图视图并定位字段。
- 保留已保存素材下载、修订历史和 PDF 导出；明确这些内容来自已保存修订，不包含尚未保存的修改。大图 Escape 关闭及焦点返回沿用共享 Dialog。
