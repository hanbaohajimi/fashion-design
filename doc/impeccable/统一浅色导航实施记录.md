# 统一浅色导航实施记录

日期：2026-10-26。用户选择第二张参考图的暖白导航、彩色 Logo，以此统一全平台外框。此前工作室与其他页面的深浅导航分支已移除。

## 落地内容

- 唯一运行时主题 `apps/web/src/styles/design-system.css` 的 navigation 色板改为暖白、深绿文字、浅灰绿选中态；主按钮与状态色保持原有含义。
- `ArchiveNavigation` 所有业务入口使用同一份外框与彩色 Logo。桌面统一 184px；账户在底部固定，项目入口顺序在各项目页面一致。
- 低于 1200px 统一为 64px 高导航栏，提供当前工作区下拉菜单及账户；工作室不再单独消失整个导航。菜单支持当前项、项目名、键盘与 Escape 返回焦点。
- 工作室 11 项入口继续按原分组提供，局部目录独立滚动；当前项进入可见范围。页面仍按图片、章节或集合采用适合任务的布局。
- 工作台窄屏可用高度与统一导航高度对应；登录表单区域使用浅灰绿色。未改后端、生成、计费、权限或保存协议。
- 跨页保留项目参数，离开未保存款式仍触发原保护。导航组件内统一控制高度，消除了首页控件样式导致的账户位置偏移。
