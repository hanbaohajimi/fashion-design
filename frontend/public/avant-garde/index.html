Three Core Paths

面向夜间创作者状态重塑的三条核心任务路径

01

情绪板无限编织

资产包不再按顺序归档，而是以流体碰撞方式拼贴。 参考图、注释、材质和趋势碎片会在空间中自行寻找邻接关系。

  • 拖拽即编织
  • 漂浮标签与笔记共层
  • 卡片碰撞时产生轻微位移
02

液态色域漫延

鼠标滑动时，颜色在界面组件上无级扩散。 色彩不是静态选项，而是随着意图在表面上缓慢捕捉、过渡和沉积。

  • 鼠标坐标驱动光场
  • CSS 变量实时扩散
  • 组件边缘出现液态高光
03

视差动态剧场

作品与资产沿着横向空间展开，形成可演示的沉浸式编排。 从设计过程到汇报展示，页面本身成为一场横向移动的展演。

  • 横向视差滚动
  • 叙事式卡段编排
  • 适合对外展示与评审

Design Tokens

Grid

Spacing

8 / 12 / 16 / 24 / 32 / 48 / 64 为主步进，关键舞台空间用 96 与 128 制造呼吸感。

Motion
