# Atelier 设计工作室

2026-11-15当前创作流程：需求分析、旧“方案生成”独立阶段与服装评估退出新请求，分析和评价在助手普通对话中完成。画布与助手仍可直接生成图片，只使用用户确认的文字、引用和参数；不强制先分析，不自动增强。已有图片、执行记录、报告、版本关系与在途任务保留。

助手输入框提供类似 WorkBuddy 的“增强提示词”星芒入口，只有主动点击才增强当前草稿和明确引用，结果回填并可撤销；用户自行编辑和发送。增强不写聊天消息、不创建分析或创作节点、不提交图片任务。期间的新输入保持原样，用户明确采用增强结果后才替换；失败、取消和作用域切换均保护原文。

2026-11-15助手可根据明确请求创建／更新1–12色色卡、添加当前账号有权使用的已有面料，移动、调整显示大小、对齐、等距分布、组合／解组和调整对象层级；可打开面料库、全部功能、画布对象及目录中的具体功能，并添加或移除创作目标的真实输入连接。尚无结果的图片和文本目标也可以连接，要求和其他引用保留。每项能力有独立的结构化说明与参数，一次处理一个明确动作，名称不唯一时澄清，锁定、隐藏、版本冲突及只读写入被拒绝。缩放只改变显示大小；打开功能、准备素材、连接输入均不自动生图。

画布动作先显示等待应用，保存成功或面板实际出现后，原消息才显示对应对象数量、素材名称或目标的完成回执。网络回执未确认时保留“继续确认画布操作”，历史和刷新不自动重放。手机打开面板时从助手返回画布，原聊天继续挂载。画布普通选择不变成聊天引用，输入框与工具栏的现有流程保持。使用例子及验证范围见[助手画布工具](../../doc/design/assistant-canvas-actions-validation.md)。

消息按实际用途分层：打开面板、移动、对齐等轻量动作以一行确认呈现，色卡与参考连接保留紧凑结构化反馈；图片任务突出实际预览、一句结果说明和“查看画布”。同一次执行的提交、进度与完成按真实执行编号和运行记录归并，过程统一折叠，重跑保持独立。失败、部分完成、待核实分别反馈，不从事件名称或模型正文推断成功。手动保存文本、导入视频与独立功能资料关联不再新增聊天回复；旧保存和版本操作仍可在助手更多菜单的“画布操作记录”查阅，画布运行历史不变。用户消息靠右且视觉减弱，普通建议与澄清保留正文。见[任务归并与显示层级验证](../../doc/design/assistant-task-transcript-validation.md)。

## Platform

2026-11-15助手采用轻量状态动效：思考时显示单行星芒、真实状态和计时，步骤点击展开；进入画布执行后由StatusMark表达等待、执行、成功、失败、部分完成及待确认。文字与结果块保持稳定，完成没有删除线或变淡。只有真实回执推动状态，快速完成不等待动画，刷新和历史不重播；离屏、收起与后台暂停，减弱动态显示静态状态。见[状态动效验证](../../doc/design/assistant-status-motion-validation.md)。

聊天消息不再显示“查看引用记录”折叠行或“未保存引用记录”占位。消息引用元数据、当前草稿的编号引用、图片预览和结果操作继续保留。真实模型操作验收及口语指令兼容见[真实模型与消息简化验证](../../doc/design/assistant-canvas-real-validation.md)。

## Users

主要用户是专业服装设计师，在桌面浏览器完成持续创作，手机用于查看、沟通和关键操作。协作角色包括所有者、编辑、评审和只读成员；角色决定可执行动作。

## Product Purpose

把需求与参考素材转化为可比较、可修改、可追溯的服装方案，并将选定款式推进到实验、系列、技术包、样衣评审和商品展示交付。

## Positioning

项目中的需求、素材、生成图片、设计说明与后续款式修订保持关联。设计师在同一张无限画布摆放素材、连接实际输入并创作；目标节点保存生成设置、结果和历史，连接关系可以隐藏。普通图片在界面称为图片、生成图或设计图，主动比较时称方案；内部 `candidate` 分类、原资产与版本关系保留兼容，旧自动标题只在展示时转换，不改写用户标题和历史正文。Agent 读取明确输入、目标和结果版本，不根据白板位置、名字或旧用途标签推断设计要求。

## Operating Context

设计师在项目间切换，查找面料和趋势，引用图片、文本和色卡，与 AI 助手梳理需求。明确生成或修改指令直接执行，讨论与助手建议不自动执行。方案经比较后保存为款式修订，后续实验、技术包、展示与评审绑定明确修订。长时间创作中需要保留草稿、当前位置、当前对象和失败恢复入口。

登录后从首页开始新创作或继续最近更新的六个项目，项目管理位于 `/projects`，跨项目查找已有文件位于 `/assets`。色料实验、印花工作台、商品展示、衣橱、实时试穿与服装秀快捷入口每次直接创建一个全新项目，进入该项目画布并展开对应功能。已有项目由首页现有项目卡片选择，不新增项目下拉选择器。发现与面料库提供参考资料，当前项目的创作、交付和资料功能沿用原工作室流程。

未登录访客先通过服装作品、面料肌理、草图与系列造型理解创作方式，再从登录或起步入口进入工作室。公开页的 AI 设计示例呈现材质、廓形与色彩方向，不作为真实用户作品或已完成业务生成的证明。

## Capabilities and Constraints

- 单图工作区聚焦查看与编辑，顶部仅保留“版本与对比”和“导出”。下载及只读分享在小浮层完成，标注导出按实际内容出现；款式保存、试穿、衣架及来源决策不再从单图窗口进入。图片默认适应可用区域，手势缩放、双击与聚焦后的F键负责视图复位。
- Next.js App Router、React、TypeScript、CSS Modules、自建共享组件；素材、创作目标与连接共用一张 tldraw 无限画布。
- 灵感便签已退役，旧便签正文清理；想法和图片参数保存在空创作目标，新的空图片默认16:9。画布对象通过“全部功能 → 画布管理”进入。不新增备注功能。底栏“添加节点”提供文本、图片、视频与资源上传/选择。文本支持手动正文编辑、明确保存和AI起草，产物保留历史；视频支持MP4/WebM导入、私有播放及放大预览，不提供生成草稿。已有资源限定本项目。空图片/文本可预先连接，执行时校验并冻结上游真实结果，详见[交互实现](../../doc/design/add-node-interaction.md)。
- `/` 对已登录用户显示创作首页，对未登录用户显示以服装作品与设计灵感为中心的公开介绍页。首页和画布标题菜单快速创建“未命名项目”并进入画布；同账号、同目标的失败或未知回执重试沿用原幂等编号，确认进入后才清除，避免重复创建。命名及可选结构化简报创建保留在 `/projects?new=1`，旧 `/?new=1` 在登录后转到该入口。 首页快捷创建保留原功能目标和幂等编号重试；画布就绪并实际展开后才消费 `openTool`，刷新不会重复创建或重新展开已完成的入口。色料、印花与商品展示沿用画布创作目标，关闭后可继续同一画布与表单草稿，左侧衣橱继续使用独立资料页。
- 公开页保留 `/login` 与 `starter=material|collection|lookbook` 的登录交接。三种造型切换只浏览预置示例，不写入项目或调用创作接口；手机导航支持键盘顺序、Escape返回、离开关闭和锚点聚焦，减弱动态时内容直接可见。公开页的局部衬线排版、影像与深绿章节不改变已登录首页或其他工作区行为。
- `/<projectId>` 保持独立画布外框，不挂载目录或展开按钮。左上角项目标题菜单提供回到主页、全部项目、创建新项目和删除项目；移除独立返回按钮与右上任务按钮。重命名、系列、生成文件、导出、历史白板、操作说明及项目任务从底部“全部功能”进入。返回和创建保留保存保护；删除要求所有者权限、明确确认及保存成功，失败留在原画布。
- 创作目标保存有序的实际引用、用户原始提示词与可见功能参数；连接、编辑要求和保存只准备输入，点击生成或明确要求 Agent 执行才创建任务。普通生图不识别素材用途，也不自动加入参考角色、权重、保留条件、人物限制、风格或负向词；明确选择的图片处理功能继续使用其真实参数。
- 重新生成在同一目标追加执行历史并保留位置；继续创作建立新目标，绑定选中结果的准确资产和版本。历史预览不修改当前结果，采用版本需要明确操作。草稿按账号、项目和目标隔离；上传完成合入最新草稿，连接与保存的迟到回执只确认原提交，保留后来修改的文字和参数，未知回执沿用原操作编号。
- 底部“全部功能模块”在当前画布打开图片工具、实验、印花、展示、系列、趋势，以及品牌资料、实时试穿、服装秀、衣橱、款式档案、技术包、样衣反馈、团队评审，复用既有领域资料、修订与任务。所有项目功能面板均不跳转独立页面，关闭后继续同一画布、视野与聊天；各表单独立保留资料选择、章节、滚动与草稿，关闭先写本机草稿，保存到项目仍是明确动作。账号、项目和对象隔离，权限与评审约束沿用原流程。选择素材只作为明确入口的输入，不按画布位置或旧用途标签推断；多选保留批量对象操作，不任取一张图。连接关系可隐藏，素材、目标和输入关系继续保留。上传图、生成图、草图图片与面料图片共用纯图片表面，历史装裱外观不再影响显示。 实时试穿关闭时释放摄像头与实时连接，保留本页未保存截图，重开不自动启动；服装秀隐藏时暂停订阅、轮询和本地播放。
- 系列规划已并入系列工作台，同一系列共用“设计方向、款式规划、系列扩展”三个分区；款式档案与商品展示独立保留。系列核心图、DNA、生成图片、规划位置、款式修订引用与PDF导出保留原身份和接口，无需数据迁移。旧规划链接仍进入工作台的规划分区，已保存位置及本机草稿保持可用，新位置草稿按系列隔离。见[整合与验证](../../doc/design/collection-workbench-validation.md)。
- 画布常驻操作使用具名图标和提示，桌面选中图片的主工具保留图标与短标签；窄屏将次要直达操作收进菜单。项目与图片名称、实际参数、菜单和表单标签继续可读。鼠标悬停、键盘聚焦或触屏长按可查看动作名称，长按松手只显示提示，下一次轻点才执行动作。
- 图片创作框顶部提供上传和画布参考，下方显示创作类型、真实比例/质量/数量、语音与生成入口。打开或关闭参数、展开或收起创作框均保留草稿；Escape先关闭参数并返回参数入口，保留当前图片选择，收起展开的创作框后回到正文。修改参数只更新本次要求，生成仍沿用明确提交、权限与未知回执恢复规则。
- 共享目录仅保留首页、项目、资产库，以及“灵感与资料”中的衣橱、面料库、发现；删除侧栏新建按钮与功能折叠组。首页新建区下方六个图标快捷入口保留。创作、交付评审、项目资料与管理功能从画布底部“全部功能”进入，原工作室 URL 与资料流程继续可用。`/wardrobe` 是静态资料页，不能成为项目 ID 或默认草稿范围。
- 无限白板中的织芽、浮窗和右侧停靠是同一助手的不同呈现。首次展开采用右下浮窗，可一键停靠；手机进入同一会话的全屏视图。按账号和项目记住呈现、位置、大小、停靠宽度与展开状态，切换保留草稿、引用、光标、阅读位置、流式回复和画布视野；旧展开/宽度偏好继续兼容。
- 主助手以直接对话创作为入口，标题打开可搜索和分页的历史；新建、停靠/浮窗、更多、收起及输入操作使用具名图标。空会话的三条起步只填草稿或打开上传，不自动发送。明确生成/修改仍使用现有自然语言执行链路，权限、幂等、SSE、未知回执和本机草稿机制继续保留。
- 引用以完整比例的小缩略图和顺序编号显示，名称/类型在提示与预览中查阅；文字和色卡也可预览。添加引用、上传或预览不自动摆放、发送或生成，只有参考图片的“放入画布”执行已有明确摆放命令。失效引用由用户主动清除，加入新引用不能静默丢弃旧项。技能涵盖内置、个人与工作区内容，非空草稿先预览后选择追加或替换，保留引用并在超长时给出明确错误。 对话的 `@` 候选和图片创作框引用列表只展示预览图或类型图标与简短名称，后台工具和内部编号不出现在候选列表；同名以序号区分，保留准确对象身份、引用限制、光标和中文输入法行为。
- 更多菜单保留设计需求、可用的当前方案与已有任务管理；主助手不提供新建定时委托、独立规划模式或项目暂停开关，旧计划/委托和后台接口继续可用，已暂停项目可由有编辑权的用户恢复。执行摘要基于真实任务，停止回复与停止已提交图片任务分开；结果保留准确历史资产和部分失败中的有效图片。
- 编号引用遵循用户录屏里的操作：桌面悬停看大图、双击临时定位画布、缩略图的 `@` 插入图号；“返回节点”恢复进入前的视野，保留选择与两个输入框的草稿。手机点击进入预览；未摆放或已替换的历史资产只预览准确原图，不伪造定位。
- 助手和画布创作框的麦克风采用点击开始／结束。识别文字在原选区进入草稿；期间编辑过正文则追加，取消不写入，超限保留文字供恢复。用户自行核对和发送。识别由浏览器提供，可能使用在线语音服务；不支持时入口给出说明。不会自动下载本地语音模型，不保存录音，也不调用平台付费模型。
- 思考采用 ThoughtLine 的星芒、扫光、计时与可折叠真实阶段记录，图片生成采用 RefineFrame。状态由真实任务驱动，不模拟进度或提前展示结果；新结果到达后逐级显现，历史图片直接显示，失败保留已有结果。旧 painting-loaders 组件、媒体与开关退役，来源和制作脚本只保留归档记录。
- 资产库汇总当前账号有权访问项目中的生成结果、上传参考及交付文件，包含已归档项目，排除已移除项目与内部诊断产物。同一上传文件在多个可访问项目中只列一次，并保留这些项目的关联。全部/图片/视频/音频/文档带数量；`kind`、`source`、`rating`、`sort`、`q` 保存在 URL，搜索覆盖文件名称、资源编号与项目名称。筛选、排序、数量与游标分页基于服务端授权后的全量 SQL 查询；类型数量响应当前搜索、来源和评级条件，不限于已加载页。
- 资产评级属于当前账号，可设1–5星或清除为未评级，不改变其他成员的选择；按星级升序或降序时未评级排在最后。评级乐观更新并在失败时回退；成功刷新保留已加载分页、滚动和焦点，筛选移除当前项时提供相邻预览/搜索的焦点落点。预览和下载继续校验私有存储权限与文件有效期，过期或缺失文件保留记录；来源入口指向实际项目、资产或文档修订。
- 资产库新增独立 `/api/assets` 读取、评级及文件访问接口，保留项目内“生成文件”的既有 API 和行为。其他环境须先执行 `pnpm db:deploy` 应用 `20261114090000_personal_asset_ratings`，再部署依赖个人评级表的 API 与前端；已有队列、模型、计费和项目权限契约继续沿用。
- 明确的生成/修改请求本身构成执行指令；发布与导出继续沿用原规则。所有执行保持幂等与历史可追溯，不能把模拟行为展示为真实执行。
- 原始图片保留比例和完整服装轮廓；引用素材、版本关系和失败原因保持可查。
- AI 图像与面料描述不能证明物性、合体性、生产尺寸、色准或报价。趋势日期未知时保留未知。
- 设计验证不自动调用付费模型。原型使用隔离模拟数据，不读写用户项目。

- 衣橱独立入口为 `/wardrobe`，默认打开最近使用的项目，标题旁以轻量可搜索选择器切换项目；显式项目优先，失效的最近项目可回退，显式失效项目保留错误。数据仍按项目组织，切换前保护未保存搭配，保留现有单品、搭配、试穿与款式关联。 画布“全部功能”保留第二个衣橱入口，在当前画布内展开当前项目衣橱；首页侧栏入口继续使用现有独立衣橱与项目切换行为。

## Product Principles

1. 让设计师先看到作品、当前对象和可执行的下一步。
2. 在模块之间保持项目、素材、款式及修订上下文。
3. 让过程可查、进展真实、错误可恢复。
4. 让人工确认、草稿和权限边界清楚可见。
5. 用相同任务比较设计方案，并区分自动化证据与真实用户反馈。

## Accessibility & Inclusion

支持键盘、可见焦点、关闭后焦点恢复、减弱动态、中文长文本和窄屏重排。正文对比度至少 4.5:1，关键控件边界及焦点至少 3:1；手机文字输入至少 16px，主要触控目标至少 44px。
