# 工作室层级推广

范围：项目内 `/studio` 的 11 个子功能。用户在商品展示包样板完成后明确要求“推广”，本轮将已经验证的层级原则扩展到其他 10 个子页，不推广至项目库、画布、面料库或趋势档案。

模式：Operate。继承 `apps/web/DESIGN.md` 的森织森林绿、暖中性色与现有系统字体，不替换品牌世界。

## Direction contract

THESIS：用对象身份、主要工作面和辅助资料建立秩序；边框保留给输入、选择和焦点，不用连续描边代替分组。

OWN-WORLD：暖中性页面承托白色工作面，辅助资料直接排在底色上；森林绿集中用于当前功能、选择与有效主操作。主标题 28px，移动端 24px，区域标题 18px，正文与说明保持中文可读性。

STORY：用户知道当前对象及修订，找到素材、规则或制作章节，理解缺项，再明确保存、提交生成或人工发布。

FIRST VIEWPORT：对象标题及次级新建操作位于顶部。款式、样衣与实验以图像主区配紧凑资料；印花保留平铺画布；技术包保留章节；系列保留位置看板；品牌以规则编辑为主；趋势以来源阅读为主。窄屏自然堆叠，无工作区内嵌滚动。主要保存操作在长页面保持可达。

FORM：按任务保留不同构图，仅共享标题、素材选择、保存状态与导航层级。延续用户指定且已验证的样板原则，无随机方案选择。seed: none (unavailable)

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 约束与证据

- API、共享类型、数据库、人工核对与权限不变；不引入自动保存、排序、封面或新导出能力。
- 新资料尚未保存与实际未保存修改分开表达。查看原图不改变选择。
- 此文件扩展商品展示包局部试用的授权范围；不是整个应用的统一双栏规范。
- 图片全部为已有项目素材，未新增展示用假数据；自动化截图的 SVG 来自原有测试 fixture，不能作为真实服装效果证据。
- 实页前后截图位于忽略目录 `output/studio-rollout/`，真实项目只有四张服装图、没有已保存的款式与交付资料；保存、发布、只读和冲突等使用既有模拟 API 测试验证，不宣称已验证真实后台写入。
