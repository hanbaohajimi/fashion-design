# 连接器工具使用指南

## 如何使用连接器创建连接

### 基本操作流程（点击模式）

1. **激活连接器工具**
   - 点击工具栏右侧的连接器按钮（两个圆点之间有曲线的图标）
   - 光标会变为十字准星 ✛
   - 画布上所有可连接元素的四周会出现蓝色锚点

2. **点击创建连接（两步点击）**
   ```
   第一次点击：源锚点 → 记录连接起点
   第二次点击：目标锚点 → 连接创建完成
   ```

   **详细步骤**:
   - **第一次点击**：点击源元素的任意锚点
     - 系统会记录源元素和源锚点
     - 靠近其他锚点时预览线会自动吸附

   - **第二次点击**：点击目标元素的任意锚点
     - 创建正式的连接线
     - 预览线消失
     - 工具保持在连接器模式，可继续创建

   **取消操作**:
   - 点击空白区域取消当前预览
   - 点击源元素自己取消操作
   - 按 Esc 键退出连接器模式

3. **连续创建多个连接**
   - 创建一个连接后，工具保持在连接器模式
   - 可以立即开始下一个连接
   - 无需重新点击工具按钮

4. **退出连接器模式**
   - 按 **Esc** 键
   - 或点击其他工具（如选择工具）

## 锚点说明

### 锚点位置
每个可连接元素有 **4 个锚点**：
- 上 (top)
- 下 (bottom)
- 左 (left)
- 右 (right)

位于元素边缘的中点位置。

### 锚点外观
- **颜色**: 蓝色 (rgba(59, 109, 255, 0.85))
- **大小**: 6px 半径（屏幕大小恒定，不随缩放变化）
- **描边**: 白色，带阴影
- **连接模式**: 所有锚点保持清晰可见，点击事件由画布工具统一处理

### 可连接的元素类型
- 图片 (Image)
- 便签 (Note)
- 色板 (Swatch)
- 面料 (Fabric)
- 框架 (Frame)

## 常见问题

### Q1: 为什么点击锚点没有反应？
**可能原因**:
- 没有激活连接器工具（工具按钮应该高亮）
- 点击位置偏离了锚点中心（锚点很小，需要精确点击）
- 画布缩放太小，锚点难以点击（尝试放大画布）

**解决方法**:
- 确保连接器工具按钮高亮显示
- 直接点击蓝色圆点的中心
- 放大画布到合适的缩放级别（100%-200%）

### Q2: 第一次点击后预览线不出现？
**原因**: 可能点击的不是锚点，或者点击了不可连接的元素。

**解决方法**:
- 确保点击的是蓝色锚点（圆形小点）
- 只有图片、便签、色板、面料、框架这几种元素可以连接
- 点击后应该立即看到半透明的预览线

### Q3: 如何取消正在创建的连接？
**方法**:
- 点击画布空白区域 → 预览线消失
- 点击源元素自己的锚点 → 取消操作
- 按 Esc 键 → 退出连接器模式

### Q4: 为什么无法连接到某个元素？
**可能原因**:
- 目标元素类型不可连接
- 尝试连接到源元素自己（不支持自连接）

**解决方法**:
- 只能连接图片、便签、色板、面料、框架这几种类型
- 确保源和目标是不同的元素

### Q5: 如何删除已创建的连接？
**步骤**:
1. 按 **Esc** 或点击选择工具，退出连接器模式
2. 点击连接线，选中它（线条会变粗）
3. 按 **Delete** 或 **Backspace** 键删除

### Q6: 预览线可以跟随鼠标吗？
**是的！** 第一次点击锚点后：
- 预览线会自动跟随鼠标移动
- 靠近其他元素的锚点时会自动吸附
- 吸附时预览线会精确连接到目标锚点

## 操作技巧

### 技巧1: 选择合适的锚点
- **水平排列**的元素：使用左右锚点
- **垂直排列**的元素：使用上下锚点
- 这样连接线更短、更美观

### 技巧2: 批量创建连接
1. 激活连接器工具一次
2. 连续创建多个连接，无需重复激活工具
3. 完成后按 Esc 退出

### 技巧3: 精确点击
- 放大画布（Ctrl + 滚轮向前）
- 锚点会更容易点击
- 完成后可以缩小查看整体效果

### 技巧4: 快速预览
- 悬停在锚点上可以看到放大效果
- 确认这是你想要的锚点后再点击

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Esc | 退出连接器模式 |
| Delete / Backspace | 删除选中的连接 |
| Ctrl + 滚轮 | 缩放画布 |
| 空格 + 拖动 | 平移画布 |

## 技术说明

### 坐标系统
- 锚点位置使用 page 坐标（世界坐标）
- 锚点大小使用屏幕坐标（缩放无关）
- 点击检测阈值：20px / camera.z

### 性能指标
- 60fps 流畅交互
- 锚点显示/隐藏 < 16ms
- 拖动响应延迟 < 16ms

### 浏览器兼容性
- ✅ Chrome / Edge（推荐）
- ✅ Firefox
- ✅ Safari
